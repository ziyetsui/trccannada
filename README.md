# 英法汉对比研究

三语比较研究阅读页，包含章节导航、文献证据状态与平行语料核验。

网站：https://ziyetsui.github.io/trccannada/

## 内容

- `index.html`：网站入口，可直接在浏览器中打开。
- `docs/`：页面引用的自编研究稿、统计数据、数据清单和分析脚本。
- `.nojekyll`：直接发布静态文件。

原书 PDF、完整 OCR、第三方论文全文和本地检索缓存保留在本地研究档案中。本网站保留研究中的出处、证据状态与限制说明。

## 发布

GitHub Pages 从 `publish/website` 分支的根目录发布。对应 PR 合并后，可将发布来源切换至 `main`。
