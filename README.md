## 教材学习室

[九份教材、八条学习线](learning-library/textbooks/)共289节原创辅助微课、648道练习。新增A2衔接与发音入门／纠音，每课提供来源定位、Markdown、图句回忆和可保存任务勾选。原书全文仅保留本机。

学习室现通过共享访问码解密进入，使用 StatiCrypt 3.5.4；无账号与数据库。可选择记住此设备7天，退出不删除学习进度。逐课下载仅在解锁后的页面中生成。
