# 法语，一点点

Oxford 起飞的 22 课、163 条例句配有逐句生成的记忆插图。每张图把谐音物件和句意中的动作联系起来，在“整句发音巧记”和“自己说一次”中显示。先听法语，再借图回忆，最后回听核对；图像与近音不代替准确发音，也不保证一次观看即可长期记住。[研究与设计依据](docs/research/visual-memory-design.md)。下载的 ZIP 同样包含插图。

直接双击 `index.html` 开始学习，无需服务器。9 册、230 课、814 条法语例句、482 道课内练习，配中文讲解、小朋友比喻、解释答案和应用任务。

网页支持搜索、学习状态、法国／加拿大法语声音选择、慢速和停止播放。实际可选声音取决于设备；没有法语声音时请在系统语音设置中添加。网页阅读无需联网，声音是否可离线使用由设备决定。学习进度只在当前浏览器保存。

原七册为参考英文框架适配的原创法语初稿，新增两册为40篇法语故事与Oxford全书的中文辅助和独立练习，尚未经过法语教师逐课审校。567 条框架条目对应不是逐句翻译或全部原书练习、录音的复刻。Introduction 原 PDF 只有节选。建议等级不是官方认证。

包内 sources/ 仅保留原书目录、目录页的 Markdown、纯文本与页图，供检查框架。完整的1,500个PDF物理页与313个EPUB文档在原工作目录的learning-library/sources/。两份新增资料全文也只在本机完整版；包内原文标签会提示使用本机完整版。不要把包内目录索引误当作完整原书。

修改 french/ 中的课文后，用 Python 3.10+ 执行 `python3 scripts/build_site.py` 重建网页。不要运行 author_curriculum.py 覆盖自己的手工修改。详见教材目录末尾说明。

页面顶部提供明／暗模式切换。首次打开跟随系统外观；手动选择后保存在当前浏览器，下次打开继续使用。
