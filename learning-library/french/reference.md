# 随手查：附录、词表与术语

## 常见动词现在时

| 主语 | être | avoir | aller | faire |
|---|---|---|---|---|
| je | suis | ai | vais | fais |
| tu | es | as | vas | fais |
| il/elle/on | est | a | va | fait |
| nous | sommes | avons | allons | faisons |
| vous | êtes | avez | allez | faites |
| ils/elles | sont | ont | vont | font |

| 主语 | pouvoir | vouloir | venir | prendre |
|---|---|---|---|---|
| je | peux | veux | viens | prends |
| tu | peux | veux | viens | prends |
| il/elle/on | peut | veut | vient | prend |
| nous | pouvons | voulons | venons | prenons |
| vous | pouvez | voulez | venez | prenez |
| ils/elles | peuvent | veulent | viennent | prennent |

规则 -er 词尾：-e、-es、-e、-ons、-ez、-ent。规则第二组 -ir 以 finir 为例：finis、finis、finit、finissons、finissez、finissent；不能套到所有 -ir 动词。

常见不规则过去分词：être→été；avoir→eu；faire→fait；prendre→pris；mettre→mis；dire→dit；voir→vu；lire→lu；écrire→écrit；venir→venu；ouvrir→ouvert；pouvoir→pu；vouloir→voulu；savoir→su。

## 时态结构速查

| 用途 | 结构 | 原创例句 | 课程 |
|---|---|---|---|
| 现在与习惯 | 现在时 | Je travaille ici. | G03、G08 |
| 过去整体事件 | avoir/être 现在时 + 过去分词 | J’ai réservé. | G09、G10 |
| 过去背景与习惯 | imparfait | Il pleuvait. | G11、G12 |
| 过去之前 | 助动词 imparfait + 过去分词 | Elle était partie. | G13 |
| 当前相连的将来 | aller 现在时 + 不定式 | Je vais partir. | G15 |
| 刚刚发生 | venir de + 不定式 | Je viens de rentrer. | G15 |
| 普通将来 | 将来词干 + 将来词尾 | Je vous écrirai. | G16 |
| 将来之前已完成 | 助动词将来时 + 过去分词 | J’aurai fini. | G16 |
| 礼貌、假设 | 将来词干 + imparfait 词尾 | Je voudrais venir. | G18、G19 |

imparfait 词尾：-ais、-ais、-ait、-ions、-iez、-aient。futur simple 词尾：-ai、-as、-a、-ons、-ez、-ont。注意 je parlerai 与 je parlerais 的语法区别；其发音对立随口音与语境可能不同，不能只凭一种声音倒推拼写。

常见将来/条件词干：être→ser-；avoir→aur-；aller→ir-；faire→fer-；venir→viendr-；pouvoir→pourr-；vouloir→voudr-；devoir→devr-；savoir→saur-。

## 虚拟式与条件结构

常用虚拟式：que je sois、que j’aie、que je fasse、que j’aille、que je puisse、que je sache、que je vienne。

si + 现在时 → 现在/将来/命令；si + imparfait → conditionnel présent；si + plus-que-parfait → conditionnel passé。这里指常见假设条件句，不包括所有 si 的用法。

同主语目的常用 pour + 不定式；不同主语目的常用 pour que + 虚拟式。avant que 与 pour que 常用虚拟式。本教材在标准书写中建议 après que 用直陈式，同时指出不同规范与实际用法存在分歧，见 G39 参考资料。

## 冠词、数量与介词

定冠词：le、la、l’、les。不定冠词：un、une、des。部分冠词：du、de la、de l’。数量后常用 de/d’：beaucoup d’eau。普通否定直接宾语常转 de/d’：pas de pain；être 后分类等情境不机械套用。

缩合：à+le=au；à+les=aux；de+le=du；de+les=des。

国家与城市：à Montréal、à Paris、au Canada、en France、aux États-Unis、en Iran。来源表达：de Paris、de France、du Canada、des États-Unis。

时间：à huit heures、en mars、en 2026、au printemps、en été、le lundi（每周一）、lundi（上下文中的某周一）。

交通：en bus、en train、en voiture、à pied、à vélo。实际表达仍需看词组与变体。

## 代词顺序

普通陈述结构中的常见次序：me/te/se/nous/vous → le/la/les → lui/leur → y → en → 动词。例：Je le lui donne。肯定命令式有不同顺序与连字符：Donne-le-moi；否定：Ne me le donne pas。见 G24、G31。

关系词：qui 作主语，que 作直接宾语，dont 对应 de 补语，où 指地点或时间，lequel 系列用于其他介词关系；ce qui/ce que/ce dont 用于没有具体名词先行词的内容。

## 音标与拼读速查

这里使用广义学习转写，不代表所有地区的精确实际音值。尤其鼻化元音在 OQLF 的魁北克转写中可能使用 [ã]、[ẽ] 等符号，而本教材常使用 /ɑ̃/、/ɛ̃/ 作为广义对照。

| 声音 | 例词 | 主要观察 | 课程 |
|---|---|---|---|
| /i e ɛ/ | si、été、mère | 前元音开口度 | P02 |
| /y u/ | tu、tout | 前圆唇与后圆唇 | P03 |
| /ø œ/ | peu、peur | 圆唇前元音开口度 | P04 |
| /a ɑ/ | patte、pâte | 口音可能区分或合并 | P05 |
| /o ɔ/ | beau、bol | 后圆唇元音开口度 | P06 |
| /ɑ̃ ɔ̃/ | sans、son | 两种鼻化元音 | P07 |
| /ɛ̃ œ̃/ | pain、brun | 口音可能合并 | P08 |
| /ʃ ʒ/ | chat、jour | 清浊摩擦音 | P11 |
| /ʁ l/ | rue、lune | 后部 r 与前部 l | P12 |
| /ɲ/ | montagne | gn 常见读法 | P13 |
| /j w ɥ/ | pied、oui、huit | 半元音过渡 | P14 |

拼写提示：ou→/u/；oi→/wa/；eau→/o/；单个 s 在两元音间常→/z/；ss 常→/s/；ch 常→/ʃ/；gn 常→/ɲ/。这些是常见线索，外来词、词汇例外和语流环境仍需查词典。

联诵、连读、省音：les amis（联诵）、avec elle（连读）、l’ami（省音）。et 后、h aspiré 前与普通单数名词后的联诵通常不做；可选联诵按语体和环境处理。

## 术语小词典

- 变位：动词按人称、数、时态与语气变化。
- 不定式：如 parler、venir 的基本词形，不等于句中可任意不变位。
- 过去分词：如 parlé、fait，参与复合时态和部分形容词结构。
- 助动词：在复合时态里帮助表达时态的 avoir 或 être。
- 直接宾语：不通过该结构要求的介词连接到动词的宾语。
- 间接宾语：通过 à、de 等结构连接；能否用 lui/leur 取决于动词。
- 配合：词形按相关主语或名词的性数调整。
- 语体：正式、普通、熟人口语等使用风格。
- 鼻化元音：发元音时允许鼻腔参与共鸣，不是简单加 n。
- 节奏组：按意义和语流组织的一小组词，组末常突出。
- h muet / h aspiré：h 都通常不读，但是否允许省音、联诵不同。
