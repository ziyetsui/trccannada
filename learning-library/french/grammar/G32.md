# G32 · 自己、彼此与不定的人

## 学完能做什么

使用重读代词、自身强调与不定代词。

## 讲解

moi、toi、lui、elle、nous、vous、eux、elles 可用于介词后或强调：avec moi、moi aussi。moi-même 等加强“自己”。自反动词的 se 在复数语境可表示彼此：Ils se parlent。quelqu’un、personne、chacun、tout le monde 各有搭配；tout le monde 按单数变位。

不定量与全称还包括 quelques（几个）、chacun（每个，单数变位）、les deux（两者）、ni…ni（既不…也不）。

## 给小朋友的比喻

一个人的名字有平时的小名，也有站出来强调自己的大名字。tout le monde 虽然站着很多人，语法却把它当一个整体来点名。

## 例句

- Viens avec moi. → 跟我来。
- Ils se téléphonent souvent. → 他们经常互相打电话。
- Tout le monde est prêt. → 大家都准备好了。
- Chacun a une clé. → 每个人有一把钥匙。
- Je ne prends ni thé ni café. → 我既不喝茶也不喝咖啡。

## 练习

### 1. avec 后应选哪个词？

- A. je
- B. moi
- C. me

### 2. Tout le monde ___ ici.

- A. est
- B. sommes
- C. sont

## 答案与原因

1. B — 介词后常用重读代词 moi。
2. A — tout le monde 在语法上使用单数动词。
