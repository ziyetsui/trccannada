# G09 · 做完的事：passé composé 与 avoir

## 学完能做什么

叙述已经发生的事件。

## 讲解

passé composé 常由 avoir 现在时 + 过去分词组成：parler→parlé、finir→fini、faire→fait、prendre→pris。它常用于把事件作为一个整体来叙述。使用 avoir 时，过去分词通常不随主语变化；前置直接宾语等配合另有规则，见 G31。

## 给小朋友的比喻

ai 像小帮手，把“已经做过”的动作卡片举起来。小帮手先变位，后面的卡片用过去分词，不能再放普通不定式。

## 例句

- J’ai réservé une table. → 我订了一张桌子。
- Nous avons fini le travail. → 我们完成了工作。
- Elle a pris le train. → 她坐了火车。

## 练习

### 1. J’ai ___ un café.

- A. prendre
- B. pris
- C. prends

### 2. “我们说过了”选哪句？

- A. Nous sommes parlé.
- B. Nous avons parler.
- C. Nous avons parlé.

## 答案与原因

1. B — avoir 后使用过去分词 pris。
2. C — parler 通常用 avoir，过去分词为 parlé。

## 一分钟应用

用 hier 写三个发生过的事件。
