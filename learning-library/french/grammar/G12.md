# G12 · 背景与事件：两种过去时

## 学完能做什么

用背景和事件讲一段小故事。

## 讲解

imparfait 展示背景、状态或正在展开的活动；passé composé 把发生的事件作为整体推进。Je lisais quand il a appelé：阅读在进行，来电进入故事。两者不是机械的“长”和“短”，同一动作按叙述视角可用不同过去时。

## 给小朋友的比喻

背景像舞台布，事件像走上舞台的小角色。布和角色一起组成故事；不能用布的大小来判断用哪个时态。

## 例句

- Il pleuvait quand je suis sorti. → 我出门时正在下雨。
- Je préparais le dîner quand elle est arrivée. → 她到时我正在准备晚饭。
- Hier, j’ai travaillé trois heures. → 昨天我工作了三个小时。

## 练习

### 1. Je dormais quand le téléphone ___.

- A. sonnait toujours
- B. a sonné
- C. sonnera

### 2. 三小时的工作作为一个完整事件可以用什么？

- A. 只能用 imparfait
- B. 现在时
- C. passé composé

## 答案与原因

1. B — 来电是推进这段过去叙述的事件，使用 a sonné。
2. C — 时间较长并不排除 passé composé，取决于叙述视角。

## 一分钟应用

用 deux phrases 描述一个背景与一个打断它的事件。
