# G29 · 把重复宾语换成小代词

## 学完能做什么

使用 le、la、les 与 l’。

## 讲解

直接宾语通常不经介词连接到动词：voir quelqu’un。le/la/les 一般放在已变位动词前：Je la vois。元音前 le/la 省音为 l’。有不定式时，代词通常靠近实际支配它的不定式：Je veux le lire。它们也能替代事或整个想法，但要看结构。

## 给小朋友的比喻

说过一次的名字可以换成小贴纸，这样不用一遍遍喊长名字。贴纸要贴在它所帮助的动作旁边，不能随便贴句尾。

## 例句

- Je vois Léa. Je la vois. → 我看见莉娅。我看见她。
- Tu connais ces mots ? Je les connais. → 你认识这些词吗？我认识。
- Je veux le lire. → 我想读它。

## 练习

### 1. “我看见他们”选哪句？

- A. Je vois les.
- B. Je leur vois.
- C. Je les vois.

### 2. Je veux lire ce livre 可改为？

- A. Je veux le lire.
- B. Je veux lire lui.
- C. Je le veux lire.

## 答案与原因

1. C — voir 接直接宾语，复数用 les 放在动词前。
2. A — le 是 lire 的直接宾语，通常放在 lire 前。

## 一分钟应用

把三个含重复名词的句子改成代词句。
