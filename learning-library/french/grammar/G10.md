# G10 · 使用 être 的复合过去时

## 学完能做什么

叙述到达、离开与自反动作。

## 讲解

部分常用动词如 aller、venir、arriver、partir 以 être 构成 passé composé，过去分词随主语性数配合：elle est partie。不能简化为“所有移动动词都用 être”：marcher 用 avoir。部分动词及物时换 avoir，如 J’ai sorti les clés。自反动词使用 être，但过去分词配合取决于宾语关系：Elle s’est lavé les mains。

## 给小朋友的比喻

有些动作牵着 être 小帮手出门，动作卡片还要穿上与主语一样的衣服。但“会走路”不是领取 être 的通行证。

## 例句

- Elle est arrivée tôt. → 她很早就到了。
- Ils sont partis ensemble. → 他们一起离开了。
- J’ai marché une heure. → 我走了一个小时。

## 练习

### 1. Marie est ___ hier.

- A. partie
- B. parti
- C. partir

### 2. 哪个通常用 avoir？

- A. venir
- B. marcher
- C. arriver

## 答案与原因

1. A — Marie 为女性单数，partie 加 e。
2. B — marcher 虽表示移动，复合过去时通常用 avoir。

## 一分钟应用

说三句到达或离开的经历，再加一句 marcher 作对照。
