# S35 · 人人都能教：把步骤讲清楚

## 学完能做什么

读懂《Tout le monde est un enseignant》的人物、事件与转折；能用自己的话复述，并在语境中理解 enseigner。

## 讲解

M. Adler发现学生不想学数学，又因雨不能出去，于是让每人准备一个五分钟小课。Lucy教画熊，Colin教折纸飞机，其他人教编发、打结和辨词。活动后大家心情更好，但数学课仍要继续。

apprendre既可表示学，也可表示教：apprendre quelque chose à quelqu’un是教某人某事。使用d’abord、puis、enfin讲步骤；命令式dessinez邀请全班一起画。

词语抓手：enseigner 表示“教、教授”。先在完整原文找到这个词，再读原书词表核对上下文；原词表是法英对照，新课中文释义为本项目编写。

## 给小朋友的比喻

每个人的口袋都有一件会做的小事，拿出来就能当五分钟老师。

## 例句

- Lucy enseigne à la classe comment dessiner un ourson. → Lucy教全班怎样画小熊。
- Colin plie une feuille pour fabriquer un avion. → Colin折一张纸来做飞机。
- Ensuite, les élèves reprennent leur cours de mathématiques. → 然后学生们继续上数学课。

## 练习

### 1. 活动结束后，数学课是否被取消？

- A. 取消了一整年
- B. 改成永远只上画画课
- C. 没有，老师宣布继续学加法

### 2. 本篇语境中的“enseigner”是什么意思？

- A. 计算
- B. 教、教授
- C. 学习

## 答案与原因

1. C — 老师一开始就说之后仍上数学课，结尾明确开始学加法。
2. B — 本篇语境中 enseigner 对应“教、教授”；应结合原文中的动作、物品和上下文辨义，另两项不符合此处语境。

## 一分钟应用

不看摘要，用三句话说出《Tout le monde est un enseignant》的开始、转折和结尾。至少一句使用 enseigner；再说出你支持判断的一处原文线索。遇到简单过去时，可先用现在时复述，再挑战复合过去时。
