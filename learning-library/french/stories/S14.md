# S14 · 鸟舍小队：找到自己的长处

## 学完能做什么

读懂《La volière》的人物、事件与转折；能用自己的话复述，并在语境中理解 coéquipier。

## 讲解

Pingouin加入由鹰指挥的动物小队，与鹰隼、猫头鹰和乌鸦训练。森林、沙漠和城市任务中它觉得自己不如别人；到南极，其他鸟很难觅食，它却能潜水捕鱼，终于看见自己对团队的价值。

être doué pour加名词或不定式，表示擅长某事；se rendre utile表示发挥用处。名字Pingouin在作品中是角色称呼，阅读不必把幻想动物设定当生物分类课程。

词语抓手：coéquipier 表示“队友”。先在完整原文找到这个词，再读原书词表核对上下文；原词表是法英对照，新课中文释义为本项目编写。

## 例句

- Pingouin est doué pour la pêche. → Pingouin擅长捕鱼。
- Il partage les poissons avec ses coéquipiers. → 它和队友分享鱼。
- Chaque membre apporte quelque chose à l’équipe. → 每位成员都为团队带来贡献。

## 练习

### 1. Pingouin在南极任务中怎样帮助队友？

- A. 飞到高空侦察
- B. 在沙漠寻找果树
- C. 潜水捕鱼并分享

### 2. 本篇语境中的“coéquipier”是什么意思？

- A. 猎物
- B. 队友
- C. 指挥官

## 答案与原因

1. C — 其他鸟难以从冰面捕鱼，它擅长潜水，带回一堆鱼。
2. B — 本篇语境中 coéquipier 对应“队友”；应结合原文中的动作、物品和上下文辨义，另两项不符合此处语境。

## 一分钟应用

不看摘要，用三句话说出《La volière》的开始、转折和结尾。至少一句使用 coéquipier；再说出你支持判断的一处原文线索。遇到简单过去时，可先用现在时复述，再挑战复合过去时。
