# S34 · 收藏什么：兴趣与实际条件

## 学完能做什么

读懂《Collection》的人物、事件与转折；能用自己的话复述，并在语境中理解 emballage。

## 讲解

Marty见朋友收藏信封邮票，也想有自己的收藏。他比较花、钱币、漫画、标本、石头与奖牌等选择，考虑兴趣、空间和成本。最后想到既吃巧克力又留下包装，清理并贴进本子；父母同意但要求不过量吃。

au lieu de表示而不是、代替；du moment que表示只要。选择过程靠排除不合适项目推进。区分collectionner le chocolat与collectionner les emballages，是理解最终方案的关键。

词语抓手：emballage 表示“包装”。先在完整原文找到这个词，再读原书词表核对上下文；原词表是法英对照，新课中文释义为本项目编写。

## 给小朋友的比喻

收藏像给喜欢的事做一册小档案，不一定要把最大最贵的东西搬回家。

## 例句

- Marty collectionne les emballages de chocolat. → Marty收藏巧克力包装。
- Il colle le premier dans un carnet neuf. → 他把第一张贴进新本子。
- Les ballons prennent trop de place dans sa chambre. → 球在他房间里占地方太多。

## 练习

### 1. Marty最后选择收藏什么？

- A. 巧克力包装
- B. 整盒永不打开的巧克力
- C. 真正的足球比赛

### 2. 本篇语境中的“emballage”是什么意思？

- A. 邮票
- B. 纸币
- C. 包装

## 答案与原因

1. A — 他想到可以吃掉巧克力，再清理包装贴进本子，两种兴趣结合。
2. C — 本篇语境中 emballage 对应“包装”；应结合原文中的动作、物品和上下文辨义，另两项不符合此处语境。

## 一分钟应用

不看摘要，用三句话说出《Collection》的开始、转折和结尾。至少一句使用 emballage；再说出你支持判断的一处原文线索。遇到简单过去时，可先用现在时复述，再挑战复合过去时。
