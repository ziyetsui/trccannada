# S11 · 巨型披萨：想象中的分工

## 学完能做什么

读懂《Les choses géantes sont faites dans une usine !》的人物、事件与转折；能用自己的话复述，并在语境中理解 garniture。

## 讲解

五位朋友在Hervé的树屋想起Aurélie生日会的巨型披萨，想象自己在工厂分工制作。有人揉面，有人煮酱，Hervé刨奶酪；Aude和Marcel悄悄省去大蒜。妈妈邀他们去快餐店时，大家已经想好要点披萨。

pendant que和tandis que可以描写同时进行的动作。把五人的任务列成表，比逐词翻译更容易掌握情节。pâte是面团；本篇词表的rapper le fromage在教学例句中规范写作râper。

词语抓手：garniture 表示“配料、馅料”。先在完整原文找到这个词，再读原书词表核对上下文；原词表是法英对照，新课中文释义为本项目编写。

## 给小朋友的比喻

五个人像五条小流水线，最后把各自的成果拼成一个圆。

## 例句

- Hervé râpe le fromage pour la pizza. → Hervé为披萨刨奶酪。
- Marcel préfère une garniture à l’ananas. → Marcel更喜欢菠萝配料。
- Pendant que la pâte lève, les amis préparent la sauce. → 面团发酵时，朋友们准备酱汁。

## 练习

### 1. Aude和Marcel在酱里省去了什么？

- A. 番茄
- B. 所有香料
- C. 大蒜

### 2. 本篇语境中的“garniture”是什么意思？

- A. 烤箱
- B. 配料、馅料
- C. 酱汁

## 答案与原因

1. C — Marcel觉得蒜味太重，两人商量后把蒜放到一边。
2. B — 本篇语境中 garniture 对应“配料、馅料”；应结合原文中的动作、物品和上下文辨义，另两项不符合此处语境。

## 一分钟应用

不看摘要，用三句话说出《Les choses géantes sont faites dans une usine !》的开始、转折和结尾。至少一句使用 garniture；再说出你支持判断的一处原文线索。遇到简单过去时，可先用现在时复述，再挑战复合过去时。
