# E16 · 增加、减少与变化

## 学完能做什么

清楚表达数量和状态变化。

## 讲解

augmenter、diminuer、monter、baisser 可描述变化，具体搭配要看对象。devenir + 形容词/名词表示变成，se rendre compte de 表意识到。法语可以直接换动词，不必寻找与英语 up/down 完全对应的粒子。

## 给小朋友的比喻

水位升高、降低，各有小箭头；小熊长大则是换了状态，不能给所有变化都画同一根箭头。

## 例句

- Les prix augmentent. → 价格上涨。
- Le bruit diminue. → 噪声减小。
- Elle devient plus autonome. → 她变得更独立。

## 练习

### 1. “价格下降”自然选哪句？

- A. Les prix font down.
- B. Les prix baissent.
- C. Les prix prennent bas.

### 2. devenir 后可接什么？

- A. 英语粒子 up
- B. 说明新状态的形容词
- C. 必须只有地点

## 答案与原因

1. B — baisser 可直接表示价格下降。
2. B — devenir autonome 描述状态变化。

## 一分钟应用

比较去年与现在，写三项变化。
