# P13 · /m n ɲ/ 与词尾鼻音

## 学完能做什么

区分鼻辅音与鼻化元音。

## 讲解

/m/ 双唇闭合，/n/ 舌尖靠前，/ɲ/ 如 montagne 的 gn。parking 等外来词可有 /ŋ/。鼻辅音有辅音闭合或阻碍，鼻化元音不是简单在结尾加 n；agneau、montagne 等需整体学习。

## 给小朋友的比喻

鼻音有时是一颗小纽扣，有时是整块布染了颜色。辅音和鼻化元音不是同一种小零件。

## 例句

- Maman arrive. → 妈妈来了。
- Nous allons à la montagne. → 我们去山区。
- Le parking est plein. → 停车场满了。

## 练习

### 1. montagne 中 gn 常对应什么？

- A. /ɲ/
- B. 连续两个清楚的 /g n/ 必然如此
- C. /ʃ/

### 2. 鼻化元音等于额外加一个完整 n 吗？

- A. 只能写 m
- B. 总是等于
- C. 不等于

## 答案与原因

1. A — 常见拼写 gn 表示 /ɲ/。
2. C — 应区分元音鼻化与鼻辅音。

## 一分钟应用

听 maman、montagne、parking，指出哪个位置是辅音。
