# P19 · 省音、连读与联诵不同

## 学完能做什么

区分 l’ami、avec elle 与 les amis。

## 讲解

省音是元音省去，书写常有撇号：le ami→l’ami。连读 enchaînement 将本来发音的词尾辅音连到后词，如 avec elle。联诵 liaison 则让平时无声的辅音在特定环境出现。h aspiré 阻止相关省音和联诵，如 le héros；h 本身通常不发音。

## 给小朋友的比喻

一座桥有三种搭法：去掉多余板子、移动原有板子、叫醒备用板子。桥看起来连着，施工方法却不同。

## 例句

- L’ami de Léa arrive. → 莉娅的朋友来了。
- Je viens avec elle. → 我和她一起来。
- Le héros est courageux. → 这位英雄很勇敢。

## 练习

### 1. avec elle 连接的是哪种辅音？

- A. 新添的 /z/
- B. 原本就发音的 /k/
- C. 平时无声的复数 s

### 2. le héros 为什么不写成 l’héros？

- A. h 必须大声发 /h/
- B. 所有 h 都这样
- C. h aspiré 阻止省音

## 答案与原因

1. B — 这是连读，avec 的 /k/ 本来就发音。
2. C — h aspiré 是词汇属性，不表示要读英语式 h。

## 一分钟应用

给 l’ami、avec elle、les amis 分别标上省音、连读、联诵。
