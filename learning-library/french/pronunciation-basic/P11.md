# P11 · ch 与 j：/ʃ/ 和 /ʒ/

## 学完能做什么

区分 chat 与 joue 中的摩擦音。

## 讲解

ch 在 chat 中读 /ʃ/，j 在 joue 中读 /ʒ/；后者通常有声带振动。g 在 e/i/y 前常为 /ʒ/，如 girafe；词源与外来词可有例外。法语 j 不必读成英语 j 那种先闭塞再释放的声音。

## 给小朋友的比喻

像轻轻发出“嘘”的气流，有一版喉咙也一起嗡嗡。不要在前面额外装一个“堵住再放开”的小门。

## 例句

- Le chat dort. → 猫在睡觉。
- Je joue. → 我在玩。
- La girafe est grande. → 长颈鹿很高。

## 练习

### 1. chat 中 ch 常读什么？

- A. /dʒ/
- B. /ʃ/
- C. /k/，本词固定如此

### 2. 法语 joue 的开头通常是？

- A. 英语式 /dʒ/ 必不可少
- B. 元音 /u/
- C. 持续的浊摩擦音 /ʒ/

## 答案与原因

1. B — chat 的 ch 为 /ʃ/，其他词仍需按词核对。
2. C — 法语 j 通常为 /ʒ/。

## 一分钟应用

慢读 chat、joue、chaud、jour，再听自己的录音。
