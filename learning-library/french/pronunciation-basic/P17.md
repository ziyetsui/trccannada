# P17 · 音节与节奏组

## 学完能做什么

按意义分小组读句子。

## 讲解

法语常将词连成节奏组，每组通常在末尾出现较明显的重音或延长。不能照搬英语每个实词都固定强调的模式。短句可一组，长句按意义和句法分组；不要在限定词与名词之间机械停顿。

## 给小朋友的比喻

句子像几串小珠子，每串最后一颗轻轻亮一下。不是每颗珠子都用力敲。

## 例句

- Je voudrais un café. → 我想要一杯咖啡。
- Demain matin, nous partirons tôt. → 明天早上我们会早出发。
- Ce petit livre est très utile. → 这本小书很有用。

## 练习

### 1. 法语节奏组的常见突出位置是？

- A. 只突出冠词
- B. 每个词第一个音节必然一样重
- C. 组末

### 2. 应否总在 un 与 café 之间停顿？

- A. 只有快读必须停
- B. 必须
- C. 不应

## 答案与原因

1. C — 法语常在组末有重音或延长。
2. C — 限定词与名词通常属于同一紧密组。

## 一分钟应用

给一句长句标出两到三个意义组，然后自然朗读。
