# P18 · 必需的联诵

## 学完能做什么

听出 les amis 与 vous avez 的连接。

## 讲解

联诵使通常无声的词尾辅音在某些元音或 h muet 开头词前发音。常见必需环境有限定词+名词、主语代词+动词：les amis 中 /z/，vous avez 中 /z/。s/x 常变 /z/，d 可为 /t/。不能遇到元音就随意连。

## 给小朋友的比喻

平时睡着的小队员，听见特定朋友走来才醒来搭桥。不是每个路口都能唤醒它。

## 例句

- Les amis arrivent. → 朋友们来了。
- Vous avez le temps. → 您有时间。
- Nous avons deux enfants. → 我们有两个孩子。

## 练习

### 1. les amis 中联诵声音常是？

- A. /z/
- B. /ʃ/
- C. /s/

### 2. 联诵是否只要后面元音就能任意做？

- A. 不是
- B. 总是
- C. 词性不影响

## 答案与原因

1. A — 限定词 les 在这里联诵为 /z/。
2. A — 联诵受句法、词汇和语体限制。

## 一分钟应用

播放 les amis、vous avez、deux enfants，模仿连接而不加停顿。
