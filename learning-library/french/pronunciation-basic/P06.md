# P06 · 圆唇后元音 /o/ 与 /ɔ/

## 学完能做什么

听辨 beau 与 bol 的元音。

## 讲解

/o/ 如 beau，通常较闭；/ɔ/ 如 bol，通常较开。eau、au 常写 /o/，o 的读音还看词和音节环境，地区也有差异。不要把两者都拉成带明显滑动的英语元音。

## 给小朋友的比喻

圆形小窗户一扇开小一点，一扇开大一点。看见字母 o 时，还要看它住在哪个词里。

## 例句

- C’est beau. → 这很美。
- Le bol est blanc. → 碗是白色的。
- Un bateau passe. → 一艘船经过。

## 练习

### 1. beau 的元音通常是？

- A. /o/
- B. /i/
- C. /ɔ̃/

### 2. bol 中 /ɔ/ 相对 /o/ 怎样？

- A. 必须读两个音节
- B. 必然带鼻音
- C. 较开

## 答案与原因

1. A — eau 在 beau 中通常为 /o/。
2. C — /ɔ/ 是较开的圆唇后元音。

## 一分钟应用

交替听读 beau、bol、bateau，避免在元音后加额外声音。
