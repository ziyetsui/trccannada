# P08 · pain、brun 与鼻音合并

## 学完能做什么

认识 /ɛ̃/、/œ̃/ 及其变体。

## 讲解

pain 常为 /pɛ̃/；brun 在保留区别的口音中含 /œ̃/。许多法国口音把 /œ̃/ 与 /ɛ̃/ 合并，加拿大等变体可保留。pain/panne 中的 n 拼写环境不同，后一词通常不以鼻化元音结尾。

## 给小朋友的比喻

有些声音像两种相近的果汁，有的地方分两杯，有的地方混成一杯。先能听懂，再练自己选定的那杯。

## 例句

- Je prends du pain. → 我拿一些面包。
- Il porte un manteau brun. → 他穿一件棕色外套。
- La voiture est en panne. → 汽车坏了。

## 练习

### 1. /œ̃/ 与 /ɛ̃/ 是否普遍保持区别？

- A. 完全不是法语音
- B. 不是，存在合并
- C. 所有人都严格区分

### 2. panne 是否与 pain 只差拼写、读音必然一样？

- A. 都没有元音
- B. 必然一样
- C. 不是

## 答案与原因

1. B — 这是已知的地区和口音差异。
2. C — 双写辅音等环境改变读法，需按词学习。

## 一分钟应用

听 pain、panne、brun；比较 fr-FR 与 fr-CA 声音。
