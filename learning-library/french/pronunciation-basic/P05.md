# P05 · 开放元音与地区差异

## 学完能做什么

清楚发 /a/，认识 /ɑ/ 变体。

## 讲解

patte 中常见 /a/；pâte 在保留区别的口音中可用 /ɑ/，但许多当代法语口音合并这一区别。加拿大法语可能保留更多音质与时长差异。初学者先保持清楚稳定，不把某个地区的合并判作错误。

## 给小朋友的比喻

两支红蜡笔有的盒子分浅红深红，有的盒子合成一种红。画面仍能看懂，不能说只准用自己的盒子。

## 例句

- La pâte est prête. → 面团准备好了。
- Le chat a une petite patte. → 猫有一只小爪子。
- Papa arrive. → 爸爸来了。

## 练习

### 1. patte 与 pâte 是否所有法语口音都区分？

- A. 一定区分且读法唯一
- B. 完全没有任何地区差异
- C. 不是

### 2. 初学者遇到地区变体宜怎样？

- A. 先理解并稳定自己的读法
- B. 把不同口音一律判错
- C. 随机改变每个词

## 答案与原因

1. C — 许多口音合并 /a/ 与 /ɑ/。
2. A — 清楚可懂与识别变体优先。

## 一分钟应用

听同一词的两种法语声音，记录差异而不急着判错。
