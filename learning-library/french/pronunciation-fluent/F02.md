# F02 · 快慢语速中的信息不丢失

## 学完能做什么

按意义调整速度而非全句一味快读。

## 讲解

自然快速语流可有弱化、省略和连接，但关键数字、否定、姓名和对比点应清楚。慢速播放可能改变语音合成的节奏，需再听正常速度。速度提升以理解和稳定为前提。

## 给小朋友的比喻

小车在直路可以快一点，遇到路标要慢下来让人看清。快不是把轮子拆掉。

## 例句

- Le rendez-vous est à quinze heures. → 预约在十五点。
- Je n’ai pas dit seize heures. → 我没说十六点。
- Je vais répéter le point important. → 我重复关键点。

## 练习

### 1. 快读时哪些内容尤其需保留清楚？

- A. 全部介词都删掉
- B. 只有句尾一个词
- C. 数字、否定与关键信息

### 2. 慢速跟读后为何再听正常速度？

- A. 只为刷新页面
- B. 慢速必定完全等同自然语流
- C. 核对自然节奏与连接

## 答案与原因

1. C — 关键信息丢失会改变实际意思。
2. C — 语音合成的速率变化可能影响节奏。

## 一分钟应用

将一个通知读两遍，关键数字保持清楚，其余自然连贯。
