# F04 · 声音接触时的变化

## 学完能做什么

理解同化而不把口语变化写进拼写。

## 讲解

相邻辅音可能互相影响清浊或发音位置，如快速语流中的 je pense 可出现清化。变化取决于语速、地区和个人风格，并非每次相同。先听辨，不强行夸张模仿；书写仍保持标准词形。

## 给小朋友的比喻

两块颜色相近的积木贴着，有时边缘看起来染到一点颜色。颜色变化不说明积木名字也换了。

## 例句

- Je pense que c’est possible. → 我觉得这是可能的。
- Une grande table est prête. → 一张大桌子准备好了。
- Je peux te le dire. → 我可以告诉你。

## 练习

### 1. 语流中的同化是否需要改标准拼写？

- A. 只要快读就改
- B. 必须
- C. 不需要

### 2. 学习同化应先重视什么？

- A. 听辨并保持可懂
- B. 故意把每个辅音变得最极端
- C. 完全忽略语境

## 答案与原因

1. C — 声音实现变化不等于词的标准拼写变化。
2. A — 自然变化应从观察实际语流入手。

## 一分钟应用

比较慢速与正常速度的一句话，记录实际听到的变化。
