# I04 · 关系与家庭：互相理解

## 学完能做什么

谈相处、矛盾和支持。

## 讲解

être sur la même longueur d’onde 表想法合拍，se serrer les coudes 表团结互助，mettre de l’eau dans son vin 表降低要求或缓和态度。不是每种家庭关系都适合用夸张习语，具体说明仍重要。

## 给小朋友的比喻

两只小熊一起拉车，脚步合拍就好走；遇到难路可以互相扶。葡萄酒比喻只是“淡一点态度”，不是让孩子喝酒。

## 例句

- Nous sommes sur la même longueur d’onde. → 我们想法很合拍。
- Dans la famille, on se serre les coudes. → 家里人彼此支持。
- Il a mis de l’eau dans son vin. → 他缓和了态度。

## 练习

### 1. se serrer les coudes 表示？

- A. 只把手肘挤在一起
- B. 团结互助
- C. 互相推开

### 2. mettre de l’eau dans son vin 常指？

- A. 拒绝任何让步
- B. 必然真的调饮料
- C. 缓和要求或态度

## 答案与原因

1. B — 该表达强调共同面对困难。
2. C — 这是常见让步与态度比喻。

## 一分钟应用

写一段家庭讨论，包含分歧与支持。
