# I21 · 决定与风险

## 学完能做什么

谈冒险、犹豫和后果。

## 讲解

peser le pour et le contre 表权衡利弊，sauter le pas 表迈出决定性一步，jouer avec le feu 表冒险招惹危险。风险判断应具体说明，不用习语代替数据或专业判断。

## 给小朋友的比喻

过小桥前先看看两边，再决定迈步。有的小桥下面很浅，有的很深，不能只喊“危险”就说清了。

## 例句

- Je pèse le pour et le contre. → 我在权衡利弊。
- Elle a décidé de sauter le pas. → 她决定迈出这一步。
- Tu joues avec le feu. → 你这样是在冒险。

## 练习

### 1. peser le pour et le contre 表示？

- A. 已经不考虑任何选择
- B. 只称重一个物体
- C. 权衡利弊

### 2. jouer avec le feu 是怎样的表达？

- A. 所有行动的中性描述
- B. 精确概率数值
- C. 对危险行为的警告

## 答案与原因

1. C — 这是决策分析的形象表达。
2. C — 它强烈提示危险，但不量化风险。

## 一分钟应用

选一个低风险生活决定，列利弊后说明选择。
