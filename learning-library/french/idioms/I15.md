# I15 · 政治、冲突与天气比喻

## 学完能做什么

辨认评价性图景。

## 讲解

être dans la ligne de mire 表成为针对对象，jeter de l’huile sur le feu 表火上浇油，une tempête dans un verre d’eau 表小题大做引发的大风波。最后一条带贬低事件重要性的评价，用于他人受困时可能不合适。

descendre dans la rue 可指走上街头示威，需按语境区分普通移动与公共行动。

## 给小朋友的比喻

两只小熊争吵，添一勺油像让火更大。说“杯子里的风暴”是在评价它小，并不说明大家真的没有受伤。

## 例句

- Cette remarque a jeté de l’huile sur le feu. → 这句话火上浇油。
- Le ministre est dans la ligne de mire. → 这位部长成为被针对的对象。
- Pour lui, c’est une tempête dans un verre d’eau. → 在他看来，这只是小题大做的风波。
- Les manifestants sont descendus dans la rue. → 示威者走上街头。

## 练习

### 1. jeter de l’huile sur le feu 表示？

- A. 加剧冲突
- B. 缓和矛盾
- C. 只给餐点加油

### 2. tempête dans un verre d’eau 是纯中性事实吗？

- A. 是精确天气测量
- B. 是
- C. 不是，带轻视或缩小严重性的评价

## 答案与原因

1. A — 这是常见冲突升级比喻。
2. C — 使用前需考虑事件与对方处境。

## 一分钟应用

解释一个冲突比喻，再改成不评价动机的中性句。
