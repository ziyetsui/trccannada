P01§A1§字母与声音不是同一回事§区分拼写、字母名和实际读音。§字母名用于拼写姓名，词中的声音用于说词。一个声音可由多个字母写出，如 eau 常读 /o/；同一字母也可能有不同读法。方括号或斜线里的 IPA 是声音提示，不应让浏览器直接朗读符号。先点完整词，再看拼写。§名字贴纸和小熊的声音不是一回事。写着 eau 的三张字母贴纸，可以一起发一个 /o/ 的声音。§Bonjour.→你好。;;De l’eau.→一些水。;;Comment ça s’écrit ?→这个怎么拼写？§eau 在常见词中通常对应几个声音？¦一个 /o/¦三个独立元音¦永远不发音¦多个字母可以共同表示一个声音。;;字母名最适合什么任务？¦拼写姓名¦替代所有单词实际读音¦自动判断词义¦字母名与词中读音需区分。§听读 eau、beau、bateau，再拼写自己的名字。
P02§A1§前元音 /i/、/e/ 与 /ɛ/§听辨并模仿三种不同开口度。§/i/ 舌位高、口较窄，如 si；/e/ 较闭，如 été；/ɛ/ 较开，如 mère。嘴唇不需要圆起。法语元音通常避免附加英语式滑动；具体 /e/ 与 /ɛ/ 的分布有地区差异，不能只凭字母无条件猜。§嘴巴像小窗户：/i/ 开小缝，/e/ 再开一点，/ɛ/ 更开一点。窗户大小只是舌位提示，不是精确的尺子。§Si.→如果；也可反驳否定问题。;;L’été arrive.→夏天来了。;;Ma mère est ici.→我母亲在这里。§/ɛ/ 与 /e/ 相比通常怎样？¦开口更大¦嘴唇必须更圆¦完全相同且从不变化¦/ɛ/ 通常为更开的前元音。;;练习法语纯元音宜怎样？¦保持较稳定的元音音质¦每次拖出额外滑音¦只念字母名字¦不额外滑动有助保持元音清楚。§慢读 si、été、mère，再把词放回短句。
P03§A1§tu 与 tout：/y/ 和 /u/§建立法语 /y/ 与 /u/ 的口形差别。§/y/ 如 tu：舌位靠前、嘴唇圆；/u/ 如 tout：舌位靠后、嘴唇圆。可先保持 /i/ 的舌位再圆唇尝试 /y/，但需听完整词核对。不要把 tu 读成英语 two，也不要用汉字谐音替代。§两个小圆嘴长得像，舌头却住在不同房间：tu 在前房，tout 在后房。看嘴唇还不够，要让耳朵一起帮忙。§Tu viens ?→你来吗？;;Tout va bien.→一切都好。;;La rue est calme.→街道很安静。§tu 的核心元音是？¦/y/¦/u/¦/a/¦tu 通常读 /ty/，是前圆唇元音。;;/y/ 与 /u/ 主要舌位区别是什么？¦前与后¦只能靠声音长短¦有没有字母 t¦两者均圆唇，但舌位前后不同。§交替读 tu、tout、rue、roue，并录一小段自听。

P06§A1§圆唇后元音 /o/ 与 /ɔ/§听辨 beau 与 bol 的元音。§/o/ 如 beau，通常较闭；/ɔ/ 如 bol，通常较开。eau、au 常写 /o/，o 的读音还看词和音节环境，地区也有差异。不要把两者都拉成带明显滑动的英语元音。§圆形小窗户一扇开小一点，一扇开大一点。看见字母 o 时，还要看它住在哪个词里。§C’est beau.→这很美。;;Le bol est blanc.→碗是白色的。;;Un bateau passe.→一艘船经过。§beau 的元音通常是？¦/o/¦/ɔ̃/¦/i/¦eau 在 beau 中通常为 /o/。;;bol 中 /ɔ/ 相对 /o/ 怎样？¦较开¦必然带鼻音¦必须读两个音节¦/ɔ/ 是较开的圆唇后元音。§交替听读 beau、bol、bateau，避免在元音后加额外声音。
P07§A1§鼻化元音：sans 与 son§区分 /ɑ̃/ 和 /ɔ̃/。§sans 常为 /sɑ̃/，son 常为 /sɔ̃/。鼻化元音中气流可经过鼻腔，不需要在末尾额外加清楚的 n。书写 an/en、on 常提示鼻化，但后接元音或双写辅音等情境有例外。§声音像走两条小通道：嘴巴和鼻子一起帮忙。不是先说元音，再在尾巴上粘一个很响的 n。§Il est sans voiture.→他没有车。;;Son sac est ici.→他或她的包在这里。;;Le vent est fort.→风很大。§sans 的常见元音是？¦/ɑ̃/¦/ɔ̃/¦/y/¦sans 常读 /sɑ̃/。;;练鼻化元音时是否应总加一个完整 n？¦不应¦必须¦只念字母名即可¦鼻化作用在元音上，不等于额外拼出 n。§对比 sans、son，再听 vent、bon 并放入短句。
P08§A1§pain、brun 与鼻音合并§认识 /ɛ̃/、/œ̃/ 及其变体。§pain 常为 /pɛ̃/；brun 在保留区别的口音中含 /œ̃/。许多法国口音把 /œ̃/ 与 /ɛ̃/ 合并，加拿大等变体可保留。pain/panne 中的 n 拼写环境不同，后一词通常不以鼻化元音结尾。§有些声音像两种相近的果汁，有的地方分两杯，有的地方混成一杯。先能听懂，再练自己选定的那杯。§Je prends du pain.→我拿一些面包。;;Il porte un manteau brun.→他穿一件棕色外套。;;La voiture est en panne.→汽车坏了。§/œ̃/ 与 /ɛ̃/ 是否普遍保持区别？¦不是，存在合并¦所有人都严格区分¦完全不是法语音¦这是已知的地区和口音差异。;;panne 是否与 pain 只差拼写、读音必然一样？¦不是¦必然一样¦都没有元音¦双写辅音等环境改变读法，需按词学习。§听 pain、panne、brun；比较 fr-FR 与 fr-CA 声音。
P09§A1§成对辅音：/p b t d k g/§通过声带与气流区分辅音。§/p t k/ 通常清，/b d g/ 通常浊；可用手轻触喉部感受振动。法语清塞音通常不需要英语式强送气。加拿大法语 t/d 在某些高前元音前可出现塞擦化，属于变体，不代表多出一个拼写字母。§有些小鼓敲时喉咙一起嗡嗡响，有些主要是嘴巴放气。别把气吹得像要吹灭蜡烛。§Le pain est bon.→面包很好吃。;;Tout est prêt.→一切准备好了。;;La gare est grande.→车站很大。§/b/ 与 /p/ 的常见区别是什么？¦声带振动特征¦永远只有长度¦一个是元音¦/b/ 通常浊，/p/ 通常清。;;法语 /p t k/ 是否需要强烈英语式送气？¦通常不需要¦每次必须很强¦只看拼写无需练¦过强送气可能影响自然度。§用轻触喉部方式读 pain、bain、tout、doux、car、gare。
P10§A1§摩擦音：/f v s z/§听辨清浊并注意 s 的拼写规律。§/f v/ 用上齿与下唇，/s z/ 用舌与前部口腔形成气流。单个 s 在两个元音之间常读 /z/，ss 通常读 /s/；有例外，需记词。liaison 中 s 常变为 /z/，不能把所有书写 s 都读成 /s/。§气流像从小缝吹过，有时喉咙一起唱歌。字母 s 像会换工作服的小朋友，要看左右邻居。§Voici du vin.→这是一些葡萄酒。;;Le poisson est frais.→鱼很新鲜。;;La maison est grande.→房子很大。§maison 中 s 通常读什么？¦/z/¦/s/¦完全不发音¦单个 s 在元音间常为 /z/。;;poisson 中 ss 通常读什么？¦/s/¦/z/¦/ʒ/¦ss 常表示 /s/，区别 poison 等词。§听读 poisson/poison，再用 maison、vin、fin 组成短句。

P12§A1§法语 r 与清楚的 l§练习 /ʁ/，避免用力刮喉咙。§常见标准法语 r 是后部的 /ʁ/，实际发音可随环境清浊变化；不必强力滚舌或刮嗓子。/l/ 舌尖接近上齿龈，常保持较清楚的前部音质。法语不同地区也存在 r 变体，目标是可懂和舒适。§r 像轻轻让后面的气流转弯，l 像舌尖去碰前面的小门。轻轻做，不要把小门撞疼。§La rue est longue.→这条街很长。;;Le livre est là.→书在那里。;;Il regarde la lune.→他看着月亮。§练法语 r 应优先怎样？¦放松并控制后部气流¦越刮喉咙越好¦必须用英语卷舌 r¦过度用力不利于稳定舒适发音。;;/l/ 的主要接触位置较靠哪里？¦口腔前部齿龈附近¦鼻腔外部¦必须喉咙深处¦/l/ 常用舌尖与齿龈附近形成。§交替读 rue、lue，再放入完整短句，感到不适就停止用力。
P13§A1§/m n ɲ/ 与词尾鼻音§区分鼻辅音与鼻化元音。§/m/ 双唇闭合，/n/ 舌尖靠前，/ɲ/ 如 montagne 的 gn。parking 等外来词可有 /ŋ/。鼻辅音有辅音闭合或阻碍，鼻化元音不是简单在结尾加 n；agneau、montagne 等需整体学习。§鼻音有时是一颗小纽扣，有时是整块布染了颜色。辅音和鼻化元音不是同一种小零件。§Maman arrive.→妈妈来了。;;Nous allons à la montagne.→我们去山区。;;Le parking est plein.→停车场满了。§montagne 中 gn 常对应什么？¦/ɲ/¦连续两个清楚的 /g n/ 必然如此¦/ʃ/¦常见拼写 gn 表示 /ɲ/。;;鼻化元音等于额外加一个完整 n 吗？¦不等于¦总是等于¦只能写 m¦应区分元音鼻化与鼻辅音。§听 maman、montagne、parking，指出哪个位置是辅音。
P14§A1§半元音 /j w ɥ/§连贯读 oui、huit 与 pied。§/j/ 如 pied，/w/ 如 oui，/ɥ/ 如 huit。这些音像元音的快速过渡，不一定各占一个完整音节。注意 huit 的 h 虽不发声，但连音用法有特殊性，不能把所有 h 词统一处理。词典与完整例句优先。§滑梯从一个口形滑到下一个口形，滑过去的一小段不必另盖一间房。不是每个写出来的元音都要单独敲一下。§Oui, je viens.→是的，我来。;;Il est huit heures.→现在八点。;;J’ai mal au pied.→我脚疼。§oui 开头常是什么？¦/w/¦/y/ 作为完整首音节¦/ʃ/¦oui 常读 /wi/。;;半元音通常怎样参与音节？¦快速过渡，未必独占音节¦每个必定两音节¦完全没有声音¦半元音常与后续元音组成一个音节。§听 oui、huit、pied，再缓慢滑动口形，不额外加音节。

P17§A1§音节与节奏组§按意义分小组读句子。§法语常将词连成节奏组，每组通常在末尾出现较明显的重音或延长。不能照搬英语每个实词都固定强调的模式。短句可一组，长句按意义和句法分组；不要在限定词与名词之间机械停顿。§句子像几串小珠子，每串最后一颗轻轻亮一下。不是每颗珠子都用力敲。§Je voudrais un café.→我想要一杯咖啡。;;Demain matin, nous partirons tôt.→明天早上我们会早出发。;;Ce petit livre est très utile.→这本小书很有用。§法语节奏组的常见突出位置是？¦组末¦每个词第一个音节必然一样重¦只突出冠词¦法语常在组末有重音或延长。;;应否总在 un 与 café 之间停顿？¦不应¦必须¦只有快读必须停¦限定词与名词通常属于同一紧密组。§给一句长句标出两到三个意义组，然后自然朗读。
