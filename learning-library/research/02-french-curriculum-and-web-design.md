# 法语教材与学习网页：原始设计记录

状态：此为原始设计记录，现已在用户授权下实施；当前交付与新增资料见 README.md 和 research/03-additional-french-books.md。下文保留当时的方案语境。

## 1. 对任务的理解

用户希望把本地 7 份 PDF 变成 AI 可以读取和检索的资料，再沿用它们的学习框架编写完整法语教材，最后做成可学习、可练习、可听发音的 HTML 或 Artifact。正文面向中文学习者，法语例句保留法语；补充说明使用幼儿也能听懂的比喻，但不能用比喻代替准确规则。

尚待确定：学习目标是加拿大生活与考试，还是通用法语；现有法语水平。目录名暗示加拿大，但不能把目录名当成用户已经确认的考试目标。

## 2. 三种交付方式

| 方式 | 好处 | 代价 |
|---|---|---|
| **推荐：Markdown 教材 + 可直接打开的独立 HTML** | 内容可长期编辑、AI 可读取；不依赖聊天平台；便于备份和迁移 | 需维护内容与生成流程；浏览器声音受设备影响 |
| 仅 Markdown 电子书 | 最容易检索和持续编写 | 不具备直接点击发音和交互练习 |
| 仅聊天平台 Artifact | 方便在平台里浏览和分享 | 平台权限、沙盒和语音支持要实测；大型教材维护困难 |

推荐以独立 HTML 为主要学习入口，Markdown 为教材的真实源文件。需要时另打包为 Artifact，而不是只留下平台内的一个页面。

## 3. 怎样“按照原书框架”

保留三个层次：

1. **教学方式**：一个单元聚焦一个知识点，先讲解和例句，再练习与答案；可按问题查询，也有推荐学习路线。
2. **组织方法**：语法按功能与句法归类；表达按核心动词、搭配、概念、功能和生活主题归类；发音按声音、词组节奏、会话和正式场景归类。
3. **覆盖关系**：为每个原书单元建立对应记录，标明保留教学目标、改为法语对应主题、合并，或被新增法语专题替代。最后检查没有悄悄漏掉一个来源板块。

不能把英语语法栏目原样当作法语规则。比如英语现在完成时不能一律译成 passé composé；英语的短语动词也没有可直接套用到法语的粒子系统。改编必须解释映射，法语例句和练习重新编写。

“完全”应当由逐单元覆盖清单证明，不是首页写上“全套”二字。原书附录、复习、答案和索引也要在法语版有相应功能。原始文献转换与原创教材分别保存。

## 4. 七份来源的法语对应路线

| 来源 | 已核实的组织方式 | 法语对应内容 | 需要处理的差异 |
|---|---|---|---|

最终法语单元数量在覆盖映射完成后锁定，不预先用“原书单元数相加”冒充完成量。可保留七册入口，也可在首页汇成“语法 / 表达 / 发音 / 习语”四条路径，避免相近册重复学习。

## 5. 内容规范与学习顺序

每课统一结构：

1. 学完能做什么，一句话。
2. 一个真实情境：如点单、问路、介绍自己或表达看法。
3. 准确讲解：法语结构、使用条件、例外与常见错误。
4. 幼儿比喻：短、具体、不引入新术语；紧接一句指出比喻的边界。
5. 原创法语例句与中文意思，每句可播放。
6. 小练习：辨认、填空、改错、重组、情境表达；题型按主题选择。
7. 答案与原因：开放题给参考答案和判断标准。
8. 一分钟复述或应用任务。
9. 相关课与参考资料。

建议学习路线：先建立拼读、最基本句子和高频表达，再按学习目标进入时态、代词、叙述与论证。资料库目录可保留原书分组，学习路线另按先修知识排序。CEFR 标注是编写者的教学估计，不能冒充官方认证。

### 教学形式的短例

**语法：否定**

- 标准结构：`ne / n’ + 已变位动词 + pas`。
- `Je ne parle pas italien.` 我不会说意大利语。
- 幼儿比喻：“我们给‘说’这个动作装两扇小门：前面是 ne，后面是 pas。两扇门关上，就是‘不说’。”
- 比喻边界：复合时态里两扇门夹住助动词；日常口语常省略 ne，但标准书写应保留。
- 对比例句：`Je n’ai pas compris.` 我没听懂。门夹住 ai，不能把它简单理解成永远夹住整段动作。

**发音：/y/ 与 /u/**

- `tu` /ty/，`tout` /tu/。
- 幼儿比喻：“说 tu 时，小嘴摆成小圆圈，小舌头却留在前面；说 tout 时，小舌头向后搬家。”
- 练习先听整词，再模仿口形。不用汉字谐音替代法语声音。
- 比喻边界：舌位仍需听辨和观察确认；单靠文字不能判断学习者发音是否正确。

**表达：avoir besoin de**

- `J’ai besoin d’aide.` 我需要帮助。
- 幼儿比喻：“小熊想搭积木，还缺一块。说 besoin，就是告诉别人‘我还需要这一块’。”
- 搭配保留 de，元音前省音为 d’；不能套英语 have 的字面意思推断全部用法。

## 6. 参考资料与核验规则

优先核对官方或教育机构来源，不拼贴网上例句。作者原创例句与外部资料分开标记。涉及语法和发音的容易混淆之处，在课尾保留具体来源链接。

- [OQLF：联诵中的声音变化](https://vitrinelinguistique.oqlf.gouv.qc.ca/23545/la-prononciation/liaisons/changements-phoniques-dans-les-liaisons)：法语联诵与声音变化核验。
- [CCDMD：FRANCOMANE](https://francomane.ccdmd.qc.ca/)：法语作为第二语言的学习资源。
- [CEFR Companion Volume](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-companion-volume-and-its-language-versions)：学习能力描述与课程分级参考。
- [France Éducation international：TCF Canada](https://www.france-education-international.fr/test/tcf-canada)：仅当加拿大考试方向确认时用于练习任务设计。
- [TCF 官方样题入口](https://www.france-education-international.fr/test/exemples-epreuves-tcf)：核对任务形式，不把原创模拟题说成官方真题。

每课检查：法语正确、中文对应、单元目标一致、答案可解释、比喻不误导、地区标签正确、相关课可跳转。语音合成不是真人示范，也不是口语评分器。

## 7. 网页布局与交互设计

设计遵循 Claude Design 官方建议：明确受众与任务、先定核心学习流程和一致的颜色/字体/组件、尽早考虑手机、检查对比度和无障碍，再逐步增加交互。[Claude Design 官方指南](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)。这是参考其方法，并非已经调用 Claude Design 创建文件。

### 首页

- 显示继续学习、语法/表达/发音/习语入口和建议路线。
- 可搜索法语词、中文知识点、单元编号。
- 可以选择级别、册别和学习状态。
- 清楚显示已完成课与尚待编写课，后者不伪装成可学习内容。

### 单元页

桌面左侧目录、中间教材、右侧小练习；手机改为单列，目录可展开。页面依次阅读，也可切换“讲解 / 练习 / 答案”。答案默认折叠，提交后显示反馈。每句法语旁都有明确的播放按钮。

视觉方向：奶白纸面、深色正文、深青色操作按钮、柔和杏色比喻框。正文约 70 字符行宽；不使用大段渐变背景或干扰学习的装饰。法语文本加 `lang="fr"`；所有按钮可用键盘操作，显示焦点，反馈区使用适当的 `aria-live`。

### 数据与生成

- Markdown 是真实源文件，含固定课号、级别、先修课和结构化练习。
- 构建脚本解析内容，生成嵌入完整数据的独立 HTML，避免 `file://` 下 fetch 本地 JSON 的限制。
- Markdown 与 HTML 分开交付，并有覆盖清单和内容状态。
- 浏览器 localStorage 保存学习进度；写入失败时本次学习仍可继续，提示无法长期保存。
- 原书转换库只放本地资料目录，不默认发布到公网。

## 8. 点击法语发音的实现要求

采用浏览器 `speechSynthesis` 和 `SpeechSynthesisUtterance`。无需为点击播放设置付费 API，但可用声音与是否联网播放取决于系统声音。不能承诺所有设备离线可用。

- 初次加载先读 `getVoices()`，监听 `voiceschanged` 后更新列表。
- 提供法语声音选择；若加拿大方向确认，优先 fr-CA，同时允许 fr-FR。
- 每次点击由用户手势触发，先取消上一句，再播放新句；支持停止与慢速。
- `lang` 必须匹配选中的声音。没有法语声音时明确提示安装/启用系统法语声音，避免悄悄用英语读法语。
- `onstart` / `onend` / `onerror` 更新播放状态，不在声音出错时假装已经播完。
- 发音课使用完整单词或短句作为合成输入，避免直接朗读 IPA 符号。
- 纯浏览器语音不提供学习者发音准确度反馈；这不属于当前功能范围。

依据：[MDN getVoices](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)、[voiceschanged 事件](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/voiceschanged_event)。

## 9. 完整交付的验收条件

1. 七个 PDF 的所有物理页均有 Markdown、索引与页图；没有把扫描书转换为空文档。
2. 目录和原书板块完成梳理，节选的缺失明确记录。
3. 法语版有逐单元覆盖清单；每一课具备讲解、比喻、原创例句、练习及答案。
4. 语法、发音和表达内容做一致性检查，无法确认的知识点不能作为定论发布。
5. HTML 本地打开可用，搜索、导航、练习、答案、进度和语音控制可操作。
6. 在真实浏览器测试桌面、手机布局、键盘访问、无声音与存储不可用等情况。自动测试可检验调用逻辑，听感和实际系统声音仍须人工试听。
7. 附使用说明、生成脚本、版本与完整性报告。完成标准以文件和检查结果为准。

## 10. 实施顺序

A. 完成原书转换和抽样核验（当前工作）。

B. 确认学习目标与本设计，建立原书单元 → 法语单元映射及完整目录。

C. 写三类代表课并校核，确定整套教材的深度与难度后，逐单元完成各册。

D. 从定稿内容生成网页，测试语音与练习，交付整套可离线浏览的文件。

本提案推荐的决策：采用“Markdown + 独立 HTML”，保留原书教学方法，按法语实际体系改编不适用的英语知识点；正文中文讲解、法语例句，每课加入幼儿比喻。
