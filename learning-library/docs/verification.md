## 复现

课程构建只需 Python 3.10+。本次使用 Python 3.13 构建和单元测试；浏览器测试使用已安装 Playwright 的 Python 3.9 与 Chromium。

```sh
python3 scripts/build_site.py
python3 -m unittest discover -s tests -p test_library.py
python3 tests/browser_check.py
```

最后一项需另行安装 Playwright 及 Chromium。原书转换需要 requirements.txt、Tesseract 和源 PDF；课程构建不需要它们。
