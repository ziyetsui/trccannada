执行 `python3 -m unittest discover -s tests -v`：课程结构、有效答案、先修无环、来源对应、缺新增框架拒绝；EPUB逐原成员字节与XML段落对照、全部reader段保留、Markdown图片/本地链接存在；Oxford每整页和半页原文本均保存，哈希与原文件一致。

执行 `python3 tests/browser_check.py`、`python3 tests/theme_check.py`、`python3 tests/additional_books_browser.py`：桌面/390px手机、9册230课、搜索/筛选、旧进度/存储失败、明暗默认/切换/记忆、原文完整显示、原书问题提醒、原文逐段法语朗读、混排页选中法语朗读、练习反馈、来源/框架/末课导航均检查。详情见同目录JSON报告。

语音测试以mock法语声音验证语种/选声/语速/取消，不能代替真实设备试听；实际可用声音取决于系统安装。无声时提示添加法语声音，不用英语声音读法语。原书CD未提供。

独立审查修复：EPUB相对链接未按OEBPS目录定位导致56处坏链；全书unit0提醒没有显示。修复后链接/图片全部存在，全书和局部提醒均可见。末轮独立审查另通过28项file://及分享包检查、12项Python单测：包含四处勘误、手机展开、法语声音路由、ZIP编辑课程并重建、来源缺失提示。T06幼儿类比中ma sœur的中文已修为“我的姐姐”，并同步课程生成脚本。
