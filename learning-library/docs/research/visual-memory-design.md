# Oxford 起飞：声音、画面与回忆

日期：2026-10-25。使用者：成年人零基础；“三岁也能懂”是直观程度的标准，不是幼儿课程认证。

## 现有方法究竟是什么

现有 814 条例句把法语的近似声音转成中文提示，再写一段脑内电影。它接近关键词法（keyword method）：声音 → 熟悉的关键词 → 关键词与目标意思互动。小画面是互动意象；文字、声音和图像提供不同的回忆线索，可以用双重编码解释其设计动机。现有发音拆解、分组跟读和自己说一次分别对应分块练习与提取练习。它不是照片式记忆，也不等于已验证所有谐音都合适。

## 研究与证据边界

补充成人与中文母语者证据：

- [Atkinson 与 Raugh，1975，俄语词汇关键词法研究（作者所在大学档案）](https://escholarship.org/uc/item/47j5c59f)：方法本身由声音联系与互动图像联系组成。重点是互动关系，不是画面越怪越好。
- [Wang 与 Thomas，1995，Effect of Keywords on Long-Term Retention—Help or Hindrance](https://stars.library.ucf.edu/facultybib1990/1498/)：作者所在大学摘要报告，关键词法的即时优势在两天后可能反转，增加练习机会可改善其保持。因此本方案必须保留主动说与复习，不能把“第一次记得快”当成“长期记住”。
- [Shao 等，2026，WordCraft，CHI 2026 作者稿](https://arxiv.org/abs/2602.00762)：针对中文母语学习者的研究指出，选合适近音、构造连贯联系和形成图像本身就困难；系统引导学习者参与三个步骤。本次使用现成图像降低起步门槛，但不能声称被动看图等同于自己参与生成。建议学习者看懂后用自己的话说明图像的联系，觉得牵强的钩子不要硬背。

1. [Pressley 等，1981，Use of a mnemonic technique to teach young children foreign language vocabulary](https://doi.org/10.1016/0361-476X(81)90039-4)：出版方摘要报告 3–6 岁儿童学习简单西班牙语时，看到近音关键词与词义互动的图片有记忆优势。本次核查摘要，不能推导成人法语整句的效果量。
2. [Attygalle 等，2025，Text-to-Image Generation for Vocabulary Learning Using the Keyword Method](https://arxiv.org/abs/2501.17099)，IUI 2025，DOI 10.1145/3708359.3712073：作者报告生成图像配合关键词法比单用关键词法提高词汇保持。支持把脑内画面外化；不能据此承诺一次观看、终身记忆或本网站的教学效果。
3. [Flack 与 Horst，2018，Two sides to every story](https://doi.org/10.1002/icd.2047)：3.5 岁儿童同时搜索两幅插图时学得更少，指向性手势可改善表现。这里把“每次一个清晰场景、目标显著”作为成人界面的设计推论；没有声称成人研究也测得相同结果。
4. [Haebig 等，2021，The Neural Underpinnings of Processing Newly Taught Semantic Information](https://pmc.ncbi.nlm.nih.gov/articles/PMC8740735/)：学前儿童的重复间隔提取支持词义学习。用于设计看图说、反馈和隔日重试。
5. [Knabe 等，2023，A lack of retrieval practice effects…](https://doi.org/10.3389/fdpys.2023.1270938)：167 名儿童、三项绘本实验未观察到提取胜过重读。提取收益取决于条件，不能包装为对任何人都有效。
6. [Hartley 与 Whiteley，2024，Do multiple exemplars promote…](https://doi.org/10.1016/j.cogdev.2024.101459)：2–3 岁儿童的多实例学习改善保持，三岁组也改善推广。提示后续应用应换真实情景，不能只认出一张固定插图；本轮不声称已经做了迁移教学。

## 三种选择与本轮决定

- 只画真实词义：易懂，但无法呈现现有近音钩子。
- 把谐音物件堆在一起：显眼，但容易只记住物件，忘记要表达的意思。
- **一个清楚的真实场景，加入和目标动作直接互动的声音钩子**：本轮采用。优先保住句意和数量关系，避免谐音喧宾夺主。

## 插图规范

范围为用户指定的 Oxford 起飞（take-off）：22 课、163 条例句，每句一图。图中不烧录整句、汉字谐音和音标，正文用可选择的 HTML 呈现；图片不承担准确标音。默认不要求模型写字；计数、时间、拼写或冠词本身就是学习对象时，允许必要的数字、字母或词语成为实物道具，不把图内文字当作校对依据。暖白背景、深色轮廓、少量青绿与橙色、扁平绘本笔触；大主体、明确的视线和手势、单一场景。人物采用成年人；三岁可理解的视觉表达不等于画成婴儿。

每张图须能回答：谁在做什么？句意中的关键对象或关系在哪里？声音钩子怎样与它互动？排除无关装饰和无法画出的文字笑话；遇到数量、否定、时态，不为塞谐音而反转含义。长句用一个共同情境，不能把所有词画成独立小格。

例如 T01:3：点单者指向一碗汤和一杯茶，服务员用小乌龟托盘送上；目标是“请给我汤和茶”，乌龟是旁边文字解释的近音辅助，不能让人以为在点乌龟汤。

## 页面与学习顺序

现有五步流程保留。在整句巧记处插入大图、简短使用提示；“自己说一次”显示同图并隐藏法语，图片替代原有泛用图标。先听准确法语 → 看图并读一次钩子 → 跟着动作说 → 隐藏法语再说 → 回听核对。隔一会和隔天再看图说；这些是练习建议，不是保证效果的最优固定间隔。

不要用“播放过”“看过图”自动判定掌握。用户可以用原有复习与标记能力记录，能独立表达且换情景仍理解才是更有用的目标。本轮不新增评分或声称已测量学习效果。
