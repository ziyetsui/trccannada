## 编写与审查

保留并修整 153 条既有故事，新写 661 条，三个互不覆盖的区段分别编写，再交换区段完整审读。交叉审查采用 79 条修订，重点是：否定、愿望与未完成动作；变位拼写；同形词读法；不熟悉的生造名字与过长音译串。没有用通用演员、招牌或字幕模板填充。

每条数据独立保存短谐音梗与脑内小电影。长句允许以原法语节奏组连接熟悉的关键近音，避免强行给每个音配陌生汉字。814 条电影文字互不重复，但这不能代替学习者的实际记忆效果。

## 页面行为

每条法语例句下有「整句发音巧记 · 谐音梗＋小画面」框，显示短口诀、具体场景和法语整句慢读；下方保留规则、分组跟读与整句复述。前四视图展示，自主回忆视图隐藏。词卡的逐词巧记继续可用。

电影是脑中想象的文字故事，本次没有生成视频或逐句插画。覆盖教学例句，不含原书阅读器正文或练习选项的逐句改编。

## 同形词校正

审稿时发现 je me sens 的动词 sens 不应使用名词 le sens 的词尾 /s/，以及 tous les… 中的限定词 tous 不应使用独立代词 /tus/；按每条例句语境修正 IPA、释义和相邻连接，避免影响其他含义。来源：[sens 的动词和名词](https://fr.wiktionary.org/wiki/sens)、[tous 的限定词与代词](https://fr.wiktionary.org/wiki/tous)。修正写在 `scripts/content/site-word-contexts.json`。
