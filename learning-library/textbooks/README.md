# 九份教材学习室

入口：[教材学习室](index.html)。九份原书形成八条学习线：B1教师用书与第3册学生课配对，不重复开设一册同内容课程。

| 学习线 | 微课 | 原书对应 |
|---|---:|---|
| 你好法语1·A1 | 49 | 4语音课、36正文课、9单元复习；三次原评估的阅读与输出任务并入R03/R06/R09 |
| 你好法语2·A2 | 48 | 教师书36课、9综合实践、3阶段检验；原创可独立练习，非学生书全文 |
| 发音快速入门 | 41 | 简介、16元音、17辅音、3半元音、4综合主题 |
| 发音与纠音 | 24 | 原7章及附录按难点重组，按需选修 |
| 简明法语·上 | 32 | 30正课、2独立复习 |
| 简明法语·下 | 31 | 28正课、3独立复习 |
| 你好法语3·B1 | 32 | 第1–24课、6综合实践、2阶段检验；逐课配对教师书 |
| 你好法语4·B1续篇 | 32 | 第25–48课、6综合实践、2阶段检验 |

合计289节原创中文辅助微课、648道原创选择练习。每课有具体任务、中文解释、类比、一个精选完整图句、近音钩子、脑内电影、发音提示、区分练习、答案理由、迁移输出与可观察自检。次级语法通过讲解、练习与输出覆盖；核心图句回忆正确不等于本课全部目标已达成。

学习顺序参考用户提供的学习计划：A1主线，简明补语音与规则，之后转向独立能力测评和考试任务。新增A2教师书补成衔接主线，但原A2学生书、练习册与音频未提供；第4册是B1续篇，并非B2。新增三本的每日90分钟、五任务安排见页面“新增三本，今天这样学”；A2共48个节点，每周5个约10周。排程不保证能力等级。

## 使用

直接打开 `index.html`，或从原有学习库的“新增教材学习室”进入。数据、界面和图像均为静态文件；页面无需联网，设备语音是否离线可用取决于系统。网页不使用在线翻译或商业朗读API。

先听设备法语朗读，看图理解，分组跟读，再隐藏文字看原图说。隐藏时连同翻译、近音、脑内电影及图片替代文字一起移除提示；揭晓后恢复。按自己真实表现记录回忆，再安排1、3、7天间隔。标记学过与复习自评分开，均仅存当前浏览器。

任务清单可实际勾选并保存在当前浏览器，刷新与课程切换后保留；原来的已学标记、复习安排继续使用。

支持全文搜索、准确课号搜索、按教材和状态筛选、单词点击朗读、慢读、停止、设备法语声音选择、明暗模式、逐课Markdown下载。全部课程Markdown见 `lessons/`；无JavaScript时也提供直接链接。原书对应见 [source-coverage.json](source-coverage.json)。

## 来源与边界

九份原书已先在本机转Markdown：原四本PDF703页，新增三本PDF514页，合计七本PDF1217物理页；另有两个EPUB共23个spine阅读文档。新增三本保留逐页文件、合并book.md、原页图、SHA256和OCR质量标记；无文本检测的10页已进行稀疏布局重识别，音标与表格仍需人工校订。源文件SHA256、分页或阅读顺序、输出与资源字节均已核验。原书全文、扫描图、原文件及私人学习计划不在此公开目录。

网站提供独立编写的中文辅助，不是原文逐字译本或全部原题复刻。扫描OCR仍需对页图校订；EPUB自定义字体音标与图片也需核对。每课保留可回查的书籍slug和物理页/章节路径。没有原教材录音的听辨项目明确记“未测”，不把设备合成声音当作原CD或考试音频。

原176课曾作跨作者审查；新增113课经目录、原页抽查及自动校验，尚未经过独立法语教师逐课审校。近音不代替真实法语声音，图像不保证一次观看即可长期记住；课程练习成绩不转换为CEFR、NCLC或TCF分数。

## 构建与维护

```sh
python3 learning-library/textbooks/build.py
python3 tests/test_textbooks_build.py -v
python3 tests/test_textbooks_browser.py -v
```

需Python和Pillow；浏览器检查还需Playwright及Chromium。所有课文来自 `content/*.json`，构建器生成HTML、逐课Markdown和来源覆盖清单。原有230课的构建器与内容保持独立。

严格构建拒绝遗漏原课ID、重复ID、先修缺失/循环、无效答案、缺图、图句四字段错配、路径越界、SHA256不符、WebP解码失败、动画或尚未通过视觉验收的图片。`--allow-pending`仅供本地草稿预览，不用于发布。

`illustrations.json`记录每张新图的精确法语、翻译、钩子、电影、prompt、工具、PNG/WebP校验值及审图结果。原176课中49个锚点精确复用46份旧Oxford资产，其余127个有独立生成图。新增113课按发音或情景精确复用已有Oxford图句：法语、翻译、近音钩子与脑内电影四字段逐字匹配，不把旧图标作新生成。修订保留旧版本与原因。底层模型名称若工具未公开则如实写“未公开”，不推测型号。

新增图片用当前可用的内置image_gen工具，一图一任务；`manage_illustrations.py`只准备任务、导入已生成文件和记录审图，不调用外部付费API。生成状态、锁与临时任务文件已忽略，不进入公开提交。原学习库的旧ZIP保持原内容，不将它描述成已包含本学习室。
