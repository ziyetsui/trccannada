# NA134 · 把未来计划安排得有先后

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

结合最近将来时、简单将来时和时间词说明计划。

## 讲解

未来不只有一种表达。现在时加明确未来时间可以说已安排的活动，aller 的现在时加原形常表达打算或将要做，简单将来时则适合预测、承诺和未来叙述。不能机械划成“很近只能 aller、很远只能简单将来”，距离并不是唯一标准。先确定想表达的是现有安排、个人意图还是对未来的判断。

图句是打电话后承诺明早再打，可以继续安排先完成什么、之后再做什么。d’abord、ensuite、après 让步骤有序；dans une semaine 定位一周以后，pendant une semaine 则是一周之久。练习先写三个未来活动，再只保留最关键的两个并加上时间。电话里还要确认对方能否接听，计划不是把自己的意愿说出来就自动成立。

本课是在第22课已学最近将来时之后比较几种未来表达，不是首次介绍 aller + 原形。复习时先从 Je vais lui écrire 还原打算联系谁，再与 Je lui écrirai demain 的简单将来时比较；两句都指未来，选择取决于如何呈现计划与预期，不能只按距离几天机械分配。

- aller + 原形：je vais travailler；不要把原形再变位。
- 未来表达由说话目的与语境选择，不只看远近。

## 给小朋友的比喻

计划像排队的三辆小车，先给每辆标时间，再说明谁先出发谁后出发。

## 例句

Je rappellerai demain matin. → 我明天上午会再打来。

近音钩子：热，拉佩儿雷，德曼，马坦。

脑内电影：我把电话轻轻放下，约好明天上午再打来；日历明早那一格放着小马，提醒我到时重新拿起听筒。

发音提示：rappellerai /ʁapɛlʁe/ 是将来形式；demain /dəmɛ̃/、matin /matɛ̃/ 尾音鼻化；别把钩子当汉语声调。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. “我打算明天学习”选哪句？

- A. Je vais étudie demain.
- B. Je vais étudier demain.
- C. Je va étudier demain.

### 2. 想说“一周后”，选哪项？

- A. pendant une semaine
- B. pour une semaine
- C. dans une semaine

## 答案与原因

1. B — je 对应 vais，后面 étudier 保持原形。

2. C — dans 表经过一段时间后；pendant 和 pour 更侧重持续或预计时长。

## 一分钟应用

准备一段三句语音留言：先做的事、之后的事、何时再联系；用两种未来表达并说清时间。

- 不看稿完成：结合最近将来时、简单将来时和时间词说明计划。
- 能用自己的内容造一句，体现：aller + 原形：je vais travailler；不要把原形再变位。
- 两道题都能说明正确项和一个错误项的差别；图句跟读后能遮文复述。

## 相关学习

先听 → 看图理解 → 分组跟读 → 隐藏文字看图说 → 揭晓回听；隔天、三天后、一周后再回忆。
