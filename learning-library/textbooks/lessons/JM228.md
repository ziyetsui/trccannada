# JM228 · 诗歌阅读：意象、重复与声音

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

写两句自己的水与记忆意象，再各用一句普通语言解释；录音比较按行停顿与按意群停顿的效果

## 讲解

原第58课以海、河流与人的情感组织诗歌比较。先找水域词和人物词如何互相映照，再读重复句怎样形成节奏。镜子、波浪、时间与记忆之间的连接是诗的表达，不需要硬还原成一个物理因果说明；比喻的价值在于让一个意象照亮另一个经验。

诗行的分行不总等于句子结束，跨行时应继续按语法和意义连接。朗读中的不稳定 e 可能因诗体、节奏和传统发生不同处理，初学先辨清主谓与意群，不把日常口语规则无条件套到所有格律诗。比较两首诗时分别记录主题、说话对象、重复方式和节奏；输出只写自己的两句意象，不复制原诗，也不假装掌握了所有诗律。

诗歌还可按行末声音识别押韵顺序：AABB 是相邻两行先同韵再换韵，ABAB 是两种韵交替，ABBA 是外层同韵包住中间一组。字母只标相同韵，不代表实际字母拼写；判断依据是读音。用新编行末词练习：soir 与 espoir 的共同结尾声音 /waʁ/ 为一组，lumière 与 rivière 的共同结尾声音 /jɛʁ/ 为一组；这里标的是共享韵部，并非单词的完整音标。按 soir—espoir—lumière—rivière 排是 AABB；按 soir—lumière—espoir—rivière 排是 ABAB；按 soir—lumière—rivière—espoir 排是 ABBA。这只训练韵式识别，不要求据此断定整首诗的格律或艺术质量。

- 意象不按科学定义理解
- 分行与句法边界未必相同
- 诗歌 e 的处理受体裁节奏影响
- 比较主题、对象、重复、节奏
- AABB 相邻韵；ABAB 交替韵；ABBA 环抱韵。
- 按实际行末声音而非拼写判断韵组。
- 原创词组 soir/espoir 与 lumière/rivière 可用来排列三种韵式。

## 给小朋友的比喻

诗的重复像潮水一次次回到岸边，每次带来相似声音，也带走一点新的感受。

## 例句

La rivière emporte mes souvenirs. → 河流带走我的回忆。

近音钩子：“里维耶尔”河水托着“苏沃尼尔”纪念盒。

脑内电影：成人站在河岸，水面托着一个装有旧照片的纪念盒向远方漂去，表达回忆流逝的意象。

发音提示：rivière /ʁi.vjɛʁ/；emporte /ɑ̃.pɔʁt/；souvenirs /su.və.niʁ/，末 s 不读；中文近音不代替法语发音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 诗行结束是否总要停成一句话？

- A. 诗歌完全没有语法
- B. 不总是，要看语法与意群是否结束
- C. 总是必须长停顿

### 2. “河流带走回忆”主要属于？

- A. 以水流表达时间或情感的意象
- B. 河流能读取人的记忆的事实证明
- C. 一条旅行行李规定

### 3. 四行末尾依次为 soir、lumière、rivière、espoir，按上述两组读音，韵式是？

- A. AABB
- B. ABAB
- C. ABBA

### 4. 要排成 ABAB，下列哪组行末词顺序合适？

- A. soir—lumière—espoir—rivière
- B. soir—espoir—lumière—rivière
- C. soir—lumière—rivière—espoir

## 答案与原因

1. B — 跨行可能继续同一语法结构，分行不等于句号。

2. A — 这是一种比喻性表达，帮助感受流逝，不是机制结论。

3. C — soir 与 espoir 属 A，lumière 与 rivière 属 B，因此顺序为 A—B—B—A。

4. A — A 组 soir/espoir 占第一第三行，B 组 lumière/rivière 占第二第四行，构成交替韵。

## 一分钟应用

写两句自己的水与记忆意象，再各用一句普通语言解释；录音比较按行停顿与按意群停顿的效果。 另只用所给四个行末词排出 AABB、ABAB、ABBA 三组，读出同韵声音，再任选一组自写四条短句。

- 原创意象与字面释义能对应
- 不会把每个换行都读成句号
- 能依声音认出三种韵式，不把字母标签当作字母拼写

## 相关学习

先听 → 看图理解 → 分组跟读 → 隐藏文字看图说 → 揭晓回听；隔天、三天后、一周后再回忆。
