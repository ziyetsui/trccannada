# JM215 · 工作与家庭：读懂选择背后的限制

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

编一个虚构人物的三阶段工作经历，每阶段写状态和原因，至少一次使用 pour 与 parce que

## 讲解

原第45课用个人工作经历组织家庭、收入与照护条件。阅读时把“本人愿望”“外部限制”“实际行动”分成三条线，才能看见选择为何改变。trancher 在这类语境可表示作出决定，而非真的切开物体；couvrir les dépenses 表示足以支付支出，也不能只按覆盖的空间意义理解。

过去习惯、完成事件和从过去看将来会在同一篇人物材料中交错。复述时先按时间节点列出工作状态，再补每次变化的原因。pour 加不定式说明目的，parce que 加完整从句说明原因，两者不能直接互换。原书社会统计属于历史阅读内容；本课练语言证据与因果链，不把一个人物故事或旧数字概括为所有女性的共同意愿。

原课还系统介绍后缀：-tion 可形成动作名词，如 organiser→organisation；-age 常形成活动或结果名词，如 laver→lavage；-eur 在 vendeur 中表示从事销售的人；-ité 在 égalité 中表示性质；-able 在 lavable 中表示可被洗的；-ment 在 calmement 中形成方式副词。后缀只是线索，不是无例外分类器：chaleur 是抽象名词而非职业，bâtiment 是建筑物名词而非方式副词。读句子时再看冠词、所修饰成分和实际意思，不能把所有末尾相同的词都塞进同一类别。

- 愿望、条件与行动分开归纳
- trancher/couvrir 关注抽象义
- pour + 不定式与 parce que + 从句
- 个案不可扩大为全体结论
- -tion/-age 常见动作名词；-eur 可指施动者，但有 chaleur 等不同类型。
- -ité 常见性质名词；-able 常见可能性形容词；-ment 常见方式副词。
- bâtiment 是名词；不能仅看 -ment 就认定副词。

## 给小朋友的比喻

选择像过桥：想去哪里是一条线，桥是否开放是另一条线，两条都要看。

## 例句

Elle travaille pour payer le loyer. → 她工作以支付房租。

近音钩子：“佩耶”硬币落进“卢瓦耶”房租信封。

脑内电影：一位成人下班后把工资中的硬币放进房租信封，桌上有住所钥匙。

发音提示：payer /pe.je/；loyer /lwa.je/；travaille /tʁa.vaj/，末 e 不另读；中文近音不代替法语发音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. pour payer le loyer 表达什么关系？

- A. 已经证明的医学结果
- B. 人物身份
- C. 目的

### 2. “个人想工作，但照护安排不足”复述应保留？

- A. 由此判定所有家庭情况相同
- B. 愿望与外部限制两层
- C. 只保留她不想工作

### 3. 比较 Il répond calmement. 与 Le bâtiment est ancien.，哪项正确？

- A. 两词都以 -ment 结尾，所以都是副词
- B. calmement 修饰回答方式；bâtiment 有冠词并作名词主语
- C. bâtiment 修饰 ancien，所以是副词

### 4. 把“可洗的衣物”写成 des vêtements ___，哪项合适？

- A. lavables
- B. lavage
- C. lavent

## 答案与原因

1. C — pour + 不定式可说明工作要达到的目的，payer 的执行者与主语一致。

2. B — 保留两层才能准确表达愿望和现实行动之间的差别。

3. B — calmement 描述 répond 的方式；le bâtiment 是 est 的主语。相同结尾不保证词类相同，须结合句法。

4. A — lavable 是可洗的形容词，这里与复数 vêtements 配合加 s；lavage 是名词，lavent 是变位动词。

## 一分钟应用

编一个虚构人物的三阶段工作经历，每阶段写状态和原因，至少一次使用 pour 与 parce que。 另外把六个后缀各找一个本课已解释的例词，任选两个放进完整句，并指出句法岗位。

- 不把限制误写成个人偏好
- 时间节点和因果关系可复查
- 六种后缀能各举一个例子
- 不会把 -ment 结尾一律判成副词
