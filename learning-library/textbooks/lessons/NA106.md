# NA106 · 用外貌特征让人认出来

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

结合身高、服装和人物关系描述一个人。

## 讲解

外貌描述只挑有辨认价值的特征，例如高矮、发色、眼镜和衣服颜色。Il est grand 描述状态，Il a les cheveux noirs 描述头发，Il porte une veste 描述穿着，这三类动词不能按中文习惯互相替换。形容词通常和它描述的名词保持性数一致，因此 une veste noire 与 des chaussures noires 的词尾不同，朗读时却不一定都能听出差别。

重读人称代词用于介词后或强调，如 avec moi、à lui、Moi, je…，不能把主语代词 je 放在 avec 后。图句提供亲属与职业这一条定位线索，接下来加外貌，便能从多人中找人。练习时先确定描述的是本人、衣服还是头发，再检查形容词跟谁配合；避免把熟悉的一个词尾推广到所有颜色和所有名词。 颜色词也有特殊形式，先练本课出现的组合。

- porter 衣服、avoir 头发/眼睛、être 高矮。
- avec 后用 moi、toi、lui、elle 等重读形式。

## 给小朋友的比喻

找人像给拼图加边角：一条特征可能模糊，三条互相补充就清楚了。

## 例句

Le frère de Nora est infirmier. → 诺拉的哥哥是护士。

近音钩子：勒，弗雷儿，德，Nora，诶，昂菲儿米耶。

脑内电影：Nora的哥哥把护理帽戴正，温柔地递来一杯米汤；他是护士，连玩具熊的绷带也包得整整齐齐。

发音提示：frère /fʁɛʁ/ 的 fr 不加元音；infirmier /ɛ̃fiʁmje/ 首音鼻化；est infirmier 注意 /t/ 联诵。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. “她穿着黑色外套”哪句合适？

- A. Elle porte une veste noir.
- B. Elle porte une veste noire.
- C. Elle est une veste noire.

### 2. “和我一起”选哪个？

- A. avec je
- B. avec me
- C. avec moi

## 答案与原因

1. B — veste 是阴性单数，noir 变 noire；être 一件外套会改变句意。

2. C — 介词后用重读代词 moi；je 是主语形式，me 是非重读宾语形式。

## 输出任务

为机场接人说五句：一条身份，再分别说身高、发色、衣服与颜色；至少使用être、avoir、porter三类结构。另说avec moi或à lui一句，并检查衣服形容词的性数。职业图句的复述不能代替外貌描述。

- [ ] 不看稿完成：结合身高、服装和人物关系描述一个人。
- [ ] 能用自己的内容造一句，体现：porter 衣服、avoir 头发/眼睛、être 高矮。
- [ ] 两道题都能说明正确项和一个错误项的差别；图句跟读后能遮文复述。
- [ ] 职业图句只提供身份线索；另不看稿描述身高、发色、衣服和颜色四项可见特征，并让听者辨认人物。

## 相关学习

先听 → 看图理解 → 分组跟读 → 隐藏文字看图说 → 揭晓回听；隔天、三天后、一周后再回忆。
