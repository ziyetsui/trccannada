# NB113 · 描述城市并连接信息

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

描述你住过的街区，用 qui、que、où 各一句，并将一个可见事实和一个个人感受分开。

## 讲解

描述城市环境时，关系从句能把两条信息连成一幅更连贯的画面。qui 在从句里作主语，que 作直接宾语，où 常标明地点或时间。选择时要看从句内部缺少哪个成分，不能看先行词是不是人：一座桥同样可以由 qui 引出，因为它可以是某个动作的主语。

城市文字还带有作者感受。高楼、雨与车流是可观察景物，压抑或自由是观看者的体验，表达时用 je trouve 或 à mes yeux 标明立场。先说一个可见细节，再说明它带来的感受，比只列“美丽、现代、大”更具体。关系从句不要无限加长，一句承担一个清楚的补充信息，读者才容易找到主干。

如果一句里出现多个地点，重述名词比连续使用代词更稳妥。

dont 填补 de 引出的成分，包括所属与动词补语：J'apprécie le calme de ce quartier → un quartier dont j'apprécie le calme（我欣赏其宁静的街区）；Je parle de ce quartier → le quartier dont je parle。对比 le quartier que j'apprécie：que 是 apprécier 的直接宾语，意思是我欣赏这个街区本身；le quartier où je me promène 则填地点。dont 已包含 de，不再写 dont j'apprécie son calme 或 dont je parle de；所属名词仍保留定冠词 le calme。

- 描述城市环境时，关系从句能把两条信息连成一幅更连贯的画面。
- 城市文字还带有作者感受。
- qui 填主语、que 填直接宾语、où 填地点/时间、dont 回指 de 补语或所属关系。

## 给小朋友的比喻

关系代词像两节车厢的连接器：接上之前先看第二节缺了哪一块。

## 例句

Je cherche un quartier où l'on peut se déplacer à pied. → 我在找一个可以步行出行的街区。

近音钩子：卡尔捷，乌隆珀

脑内电影：成年人拿着的路牌，把一个街区的房子和步行小路接在一起。画面不出现文字、标签或字幕。

发音提示：quartier /kaʁtje/；où l'on 的 l 是便于衔接的形式，不另加语义。近音只帮助回忆，法语发音以设备朗读和发音要点核对。

## 练习

### 1. 从句需要地点：un quartier ___ on peut marcher.

- A. que
- B. où
- C. dont

### 2. 结合完整句，哪项解释准确？

- A. 我寻找一个禁止行人进入的街区。
- B. 我已经找到必须开车才能离开的街区。
- C. 我在找一个可以步行出行的街区。

### 3. 合并 J'aime ce quartier. Les rues de ce quartier sont calmes.

- A. J'aime ce quartier dont les rues sont calmes.
- B. J'aime ce quartier que les rues sont calmes.
- C. J'aime ce quartier dont ses rues sont calmes.

## 答案与原因

1. B — où 表在该街区；que 是直接宾语，dont 回指 de 补语。

2. C — 句意应保留动作、时间、否定或条件关系：我在找一个可以步行出行的街区。

3. A — les rues de ce quartier 的 de 所属由 dont 回指，保留 les rues；que 不填所属，ses 与 dont 重复。
