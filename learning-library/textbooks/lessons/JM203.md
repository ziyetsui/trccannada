# JM203 · 用 dont 连接带 de 的信息

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

介绍一个你谈论的项目和一位你知道姓名的人，各造 dont 句；再用中性 le 回答一个状态问题

## 讲解

dont 能把一个需要 de 的关系接到先行词后面。先还原完整结构：parler de ce projet 变为 le projet dont je parle；le nom de cette personne 则可在从句中保留 le nom，让 dont 表达所属连接。关键是确认 de 关系，而不是看到“某人的”或“关于”就随意插入 dont。

中性 le 可以回指一种身份、性质或整段内容，不随所代形容词阴阳性变成 la 或 les。例如问是否准备好，回答 je le suis，le 回指 prêt 或 prête 这项状态。它与代替阳性物件的直接宾语 le 字形相同但范围不同。pour 也可表示目的、用途或立场，阅读时要看后接的是名词、不定式还是时间长度，不把所有 pour 都硬译成“为了”。若从句已经通过关系词表示所属，通常不再保留同一关系的物主限定词；可以先拆成两句完整陈述，检查重复表达究竟发生在哪里。

- dont 回指 de 关系
- dont 从句避免重复 de 或物主限定词
- 中性 le 可回指性质与内容
- pour 的意义取决于结构

## 给小朋友的比喻

dont 像一枚把 de 关系折进夹层的回形针，夹好了就不再露出第二个 de。

## 例句

Voici le projet dont je parle. → 这就是我所谈的项目。

近音钩子：“东”边的项目夹被讲话者举起。

脑内电影：成人在会议桌旁举起放在东侧的项目夹，向听众介绍正在谈论的项目。

发音提示：dont /dɔ̃/ 的 t 不读；projet /pʁɔ.ʒɛ/；parle /paʁl/ 不添加尾元音；中文近音不代替法语发音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. parler de ce livre 合并为 le livre ___ je parle，选？

- A. qui
- B. dont
- C. que

### 2. 女性回答“我准备好了”Je le suis. 中 le 是否改成 la？

- A. 不用，le 回指 prête 这个状态
- B. 必须用 la
- C. 必须用 elles

## 答案与原因

1. B — parler de 引出 de 补语，dont 承担这个连接关系。

2. A — 中性 le 无性数变化，回指表语状态而不是某个阴性实物。

## 一分钟应用

介绍一个你谈论的项目和一位你知道姓名的人，各造 dont 句；再用中性 le 回答一个状态问题。

- 每句 dont 能还原出 de 结构
- 不在 dont 从句重复物主关系

先听 → 看图理解 → 分组跟读 → 隐藏文字看图说 → 揭晓回听；隔天、三天后、一周后再回忆。
