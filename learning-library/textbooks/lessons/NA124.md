# NA124 · 用可执行的建议准备面试

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

读懂面试建议，用命令式安排准备步骤。

## 讲解

建议的价值在于对方能照着做。面试准备可分成到场、问候、表达能力和提问四步；读指南时辨认哪些是动作指令，哪些是评价或条件。命令式通常省略主语，却仍有不同人称形式，正式地对一位应聘者说话也可用 vous 形式。否定建议不要只在句尾添 pas，必须看完整结构与代词位置。

图句把两个指令连在一起：先进入，再坐下；asseyez-vous 的代词在肯定命令式里跟在动词后，用连字符连接。不能把这种位置直接套进陈述句 Vous vous asseyez。练习准备一份三步小指南，再模拟应聘者用 Je sais… 说明技能、Je peux… 说明可用时间。给出的能力应是设定或真实情况，不靠语法完整就夸大经历。

- 肯定命令式 asseyez-vous 与陈述句 vous vous asseyez 词序不同。
- 能力、意愿、时间条件应分开说。

## 给小朋友的比喻

面试指南像出门前的小便签，写“带钥匙”比写“表现优秀”更能照着做。

## 例句

Entrez et asseyez-vous, s’il vous plaît. → 请进，请坐。

近音钩子：昂特雷，诶，阿塞耶乌；西尔，乌，普莱。

脑内电影：我请客人进门再坐下，门边的小椅子自己滑出来；乌龟端着托盘等客人坐好，礼貌地迎接到家。

发音提示：Entrez /ɑ̃tʁe/ 的词首鼻化；asseyez-vous /aseje vu/ 留意 /j/ 滑音；s’il vous plaît 的 plaît 不读末 t。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 哪一条建议最可执行？

- A. Soyez parfait partout.
- B. Préparez deux questions.
- C. Ayez toujours de la chance.

### 2. “请坐”用正式肯定命令式选哪句？

- A. Vous vous asseyez, s’il vous plaît.
- B. Vous asseyez-vous, s’il vous plaît.
- C. Asseyez-vous, s’il vous plaît.

## 答案与原因

1. B — 准备两个问题是可观察的行动；完美和好运不能直接按步骤完成。

2. C — asseyez-vous 是命令式，省略主语，代词后置；另外两项分别是陈述与疑问语序。

## 一分钟应用

为虚构面试写三条肯定建议与一条否定建议；再用两句说一个技能和可以工作的时间。

- 不看稿完成：读懂面试建议，用命令式安排准备步骤。
- 能用自己的内容造一句，体现：肯定命令式 asseyez-vous 与陈述句 vous vous asseyez 词序不同。
- 两道题都能说明正确项和一个错误项的差别；图句跟读后能遮文复述。

## 相关学习

先听 → 看图理解 → 分组跟读 → 隐藏文字看图说 → 揭晓回听；隔天、三天后、一周后再回忆。
