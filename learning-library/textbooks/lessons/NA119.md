# NA119 · 写旅行邮件，说到达与离开

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

用 être 复合过去时讲行程，并区分 pour 与 dans。

## 讲解

一部分常见不及物动词在复合过去时中用 être，如 aller、arriver、partir、rester。它们的过去分词通常与主语配合：Elle est arrivée、Ils sont partis。不能简单记成“所有移动动词都用 être”，因为 marcher 等用 avoir；个别动词在及物用法下也可能改用 avoir。本课先把常见行程动词与助动词一起记住。

图句把到达这一事件与 hier 绑定，可以继续补何时离开、停留多久。pour 加时长常说预计持续多久，dans 加时长表示从现在起过多久再发生；二者的方向不同。叙述时先用时间线标到达点、停留段和将来的返回点，再选表达。若用 y 替代前面说过的目的地，复合过去时里它位于助动词前，如 J’y suis allé。 说话者是女性时可用书写的 e 提醒配合，即使朗读时听不出差异。

- être 助动词的过去分词注意主语性数配合。
- dans trois jours 三天后；pour trois jours 预计三天之久。

## 给小朋友的比喻

旅行时间线有站点和路段：dans 指下一站还隔多远，pour 指准备走多长一段。

## 例句

Ma sœur est arrivée hier. → 我姐姐昨天到了。

近音钩子：马，瑟儿，诶，阿里韦，耶儿。

脑内电影：我姐姐昨天到了，小马拉着她的行李进门；昨天那页日历还留在桌上，姐姐已经把外套挂好。

发音提示：sœur est 的 /ʁ/ 自然接到 /ɛ/；arrivée /aʁive/ 的 -ée 与 -é 读音相同，拼写配合仍要检查。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 两个女性说“我们到了”，选哪句？

- A. Nous avons arrivées.
- B. Nous sommes arrivé.
- C. Nous sommes arrivées.

### 2. “我三天后回来”应选？

- A. Je rentre pour trois jours.
- B. Je rentre dans trois jours.
- C. Je rentre trois heures.

## 答案与原因

1. C — arriver 用 être；女性复数主语对应 arrivées。

2. B — dans trois jours 定位三天后的返回；pour trois jours 表计划停留的长度。

## 输出任务

写四句旅行近况：何时到达、和谁到达、准备停留多久、过多久回来；标出两个不同助动词。

- [ ] 不看稿完成：用 être 复合过去时讲行程，并区分 pour 与 dans。
- [ ] 能用自己的内容造一句，体现：être 助动词的过去分词注意主语性数配合。
- [ ] 两道题都能说明正确项和一个错误项的差别；图句跟读后能遮文复述。
