# NA102 · 介绍身边的人

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

用职业和家庭关系介绍第三人称。

## 讲解

介绍别人时先让听者知道人物，再补职业或关系。C’est 后接带限定词的名词组，例如 C’est une amie；Il est、Elle est 后直接说一般职业时通常不用冠词。Ma sœur est architecte 把亲属关系和职业连在一起，architecte 在这个结构中没有 une。换成“这是一位建筑师”时，C’est une architecte 的构造就不同了。

名词的阴阳性与人物的性别有时相关，但仍要连冠词一起学；le、la 遇到元音或哑音 h 常省成 l’。不要看到 l’ 就以为这个词没有性别。先用两句介绍一位真实或虚构亲友，再把她换成他，检查人称、亲属词和职业形式。谈职业不必猜别人真实身份；练习可明确声明人物是自己设计的。 同一职业可能有不同的阴阳形式，遇到不熟悉的名称先查词表再使用。

- 职业作一般表语通常无冠词：Elle est médecin。
- C’est une amie 与 Elle est amie 不能机械互换。

## 给小朋友的比喻

先把人物请到聚光灯下，再给他一张职业名片。

## 例句

Ma sœur est architecte. → 我姐姐是建筑师。

近音钩子：马，瑟儿，诶，阿儿希泰克特。

脑内电影：我姐姐戴着建筑师帽，小马帮她搬尺子；她画出房屋图纸，一栋小屋照着图慢慢搭起来。

发音提示：sœur /sœʁ/ 保持前圆唇；est architecte 可有 /t/ 联诵；architecte /aʁʃitɛkt/ 末尾辅音群不加“呃”。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. “她是一位医生”，单纯陈述职业选哪句？

- A. Elle est une médecin.
- B. Elle est médecin.
- C. Elle a médecin.

### 2. 哪个写法保留了 étudiant 的冠词省音？

- A. le étudiant
- B. la étudiant
- C. l’étudiant

## 答案与原因

1. B — 一般职业表语用 être 加无冠词职业；此处不是强调“某种医生”的特殊用法。

2. C — 元音开头前 le 省为 l’；省音不取消 étudiant 的阳性。

## 输出任务

用四句介绍一位亲友：姓名、关系、职业、居住城市；再用 C’est 重新介绍此人。

- [ ] 不看稿完成：用职业和家庭关系介绍第三人称。
- [ ] 能用自己的内容造一句，体现：职业作一般表语通常无冠词：Elle est médecin。
- [ ] 两道题都能说明正确项和一个错误项的差别；图句跟读后能遮文复述。
