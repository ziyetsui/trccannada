# NB114 · 询问展览并辨认形容词位置

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

给虚构花园展写一封咨询信，交代参观人数与日期，问三个实用问题，并正确使用两项形容词搭配。

## 讲解

询问展览信息时，先说自己的参观需要，再问开放时间、费用、预约与导览。修饰名词的形容词通常后置，但常见短形容词有前置习惯；更要注意位置可能改变意义。un ancien jardin 是原来的花园，un jardin ancien 强调历史悠久，不能只靠一个中文词判断。

阅读花园或展览介绍时，把客观条件与宣传评价分开：面积、日期较容易核实，exceptionnel 等评价需要具体内容支持。写咨询信可以先给日期和人数，再逐项问问题。不要把所有形容词都放在名词前，也不要机械地全部后置；先学常见搭配，再比较位置改变时的意义，能避免把参观对象描述成另一回事。

语音小课（第四单元节奏组与重音）：法语句子按意义成组，常在组末最后一个实际发音音节上落较明显重音，不给每个词都施加汉语式重读。用原创句演示：Demain matin / nous visiterons le jardin / avec un guide。开头时间短语作为一个组，visiterons 与宾语通常保持同组，不能随意切成 nous visiterons le / jardin。陈述中的前组可作轻微延续上扬，最终句末下降；这是按此信息结构的朗读方案，不是每个斜线都必须升调。对比同一材料，先按意义画组，再用录音检查是否停在介词、冠词或代词之后。设备朗读只作参考，原教材音频的升降与组界辨认仍记未测。

- 询问展览信息时，先说自己的参观需要，再问开放时间、费用、预约与导览。
- 阅读花园或展览介绍时，把客观条件与宣传评价分开：面积、日期较容易核实，exceptionnel 等评价需要具体内容支持。
- 节奏组按意义划分，主要重音在组末；不拆冠词与名词，不把延续上扬当作绝对规则。

## 给小朋友的比喻

形容词像贴纸：有些贴前面像名字，有些贴后面像说明，换位置可能换意思。

## 例句

Nous visiterons un ancien jardin devenu un espace public. → 我们将参观一座已经变为公共空间的原有花园。

近音钩子：安南西安，扎尔丹

脑内电影：一个的旧花园牌被保留在门口，围墙打开，居民一起走进公共绿地。画面不出现文字、标签或字幕。

发音提示：ancien /ɑ̃sjɛ̃/ 两个音节含鼻化元音；jardin /ʒaʁdɛ̃/。近音只帮助回忆，法语发音以设备朗读和发音要点核对。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 明确说一位男性过去的邻居：“我原来的邻居”：mon ___ voisin（homme）。

- A. ancienne
- B. ancien
- C. anciennes

### 2. 结合完整句，哪项解释准确？

- A. 我们将参观一座已经变为公共空间的原有花园。
- B. 我们将参观一座从未对公众开放的新建筑。
- C. 我们将把所有公共花园改成私人住宅。

### 3. 在普通中性朗读中，哪个分组保留了完整名词组？

- A. Nous visiterons le / jardin avec / un guide.
- B. Nous visiterons le jardin / avec un guide.
- C. Nous / visiterons le / jardin / avec un / guide.

## 答案与原因

1. B — voisin 此处明确男性单数，用 ancien；前置表示原来的，ancienne 为阴性，anciennes 为阴性复数。

2. A — 句意应保留动作、时间、否定或条件关系：我们将参观一座已经变为公共空间的原有花园。

3. B — 第二项保留 le jardin 与 avec un guide；其余切开冠词、介词与其核心成分，造成不自然停顿。

## 一分钟应用

给虚构花园展写一封咨询信，交代参观人数与日期，问三个实用问题，并正确使用两项形容词搭配。

补充迁移：在自己的咨询信中选三句，按意义划节奏组、圈出组末重音音节，录读一遍。说明一处为什么不在冠词或介词后停；原声辨认标未测。

- 完成并保存本课规定的输出：给虚构花园展写一封咨询信，交代参观人数与日期，问三个实用问题，并正确使用两项形容词搭配。
- 让伙伴根据输出说出人物、动作与条件；若无法复述，标出并改写一处歧义。
- 三句分组不拆冠词/名词，至少能解释一处停顿；不宣称原教材音频听辨通过。
