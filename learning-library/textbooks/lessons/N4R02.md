# N4R02 · 综合实践：比较套餐并解释金钱选择

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

自拟两种月度套餐，列总费用、承诺期、限制和用户需求，用八句推荐并回应一项反对理由。

## 讲解

推荐通信或消费套餐，必须先知道使用者需求，再比较同一计费基准下的费用、承诺期与限制。最低标价不一定是最低总成本，无承诺期也不等于包含所有功能。把已知条件填进表格，资料没写清的地方标待确认，避免为了给出漂亮答案而补造细则。

讲金钱如何影响生活，则要把收入、选择与价值判断分开。高收入不必然意味着满意，低支出也不证明生活质量下降。使用具体事件说明决定，再用强调句突出真正重要的因素。对历史套餐只作阅读训练，不当作今天可购买产品。原创练习自行设置两种透明方案，让听者能从你的解释独立核算并作决定。

- 推荐通信或消费套餐，必须先知道使用者需求，再比较同一计费基准下的费用、承诺期与限制。
- 讲金钱如何影响生活，则要把收入、选择与价值判断分开。

## 给小朋友的比喻

套餐像两只不同大小的杯子：先换成同一容量，才能比较每杯究竟花多少钱。

## 例句

Ce n'est pas le prix annoncé qui détermine le coût final. → 决定最终费用的并不是宣传价格。

## 练习

### 1. 强调句主语用？Ce n'est pas le prix ___ détermine…

- A. que
- B. où
- C. qui

### 2. 结合完整句，哪项解释准确？

- A. 决定最终费用的并不是宣传价格。
- B. 宣传标价永远等于最终费用。
- C. 最终费用与任何付款条件都无关。

## 答案与原因

1. C — prix 是 détermine 的主语，用 qui；que 用于直接宾语等成分。

2. A — 句意应保留动作、时间、否定或条件关系：决定最终费用的并不是宣传价格。
