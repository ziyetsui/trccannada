# N434 · 用先将来时安排环保行动

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

为家庭设计七日减废计划，写两句先将来时加将来时，给一项可记录指标和一项限制。

## 讲解

环保行动要从可观察的小步骤说起：关机、分类、减少不必要包装，比“保护地球”更容易检查。把两件未来行动排序时，先将来时表示在另一个未来时刻之前已经完成，由 avoir 或 être 的将来时加过去分词构成。不是所有未来动作都要用先将来时，只有强调先完成才需要。

例如先完成讨论，再启动计划，quand 后的完成动作可用先将来时，主句用简单将来时。行动倡议应写清负责人、频次和记录方式，并承认一项成本或限制。不要把一次选择夸张成必然解决整体环境问题；将结果写成待观察的指标，才能知道方案有没有做到它承诺的事。

- 环保行动要从可观察的小步骤说起：关机、分类、减少不必要包装，比“保护地球”更容易检查。
- 例如先完成讨论，再启动计划，quand 后的完成动作可用先将来时，主句用简单将来时。

## 给小朋友的比喻

先将来时像两张明天的待办卡：第一张盖好完成章，第二张才开始。

## 例句

Quand nous aurons réduit les déchets, nous comparerons les résultats. → 等我们减少了垃圾之后，我们会比较结果。

近音钩子：欧龙雷迪，雷祖尔塔

脑内电影：成年人先把明显变少的垃圾袋放上秤记录，再转到桌边比较前后两组数值。画面不出现文字、标签或字幕。

发音提示：aurons /oʁɔ̃/；réduit /ʁedɥi/ 的 uit 发 /ɥi/。近音只帮助回忆，法语发音以设备朗读和发音要点核对。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 未来先完成：Quand nous ___ le tri, nous sortirons.

- A. avions terminé
- B. aurons terminé
- C. terminerions

### 2. 结合完整句，哪项解释准确？

- A. 我们已比较完结果，因此以后不再减少垃圾。
- B. 我们还没做任何改变就知道所有结果。
- C. 等我们减少了垃圾之后，我们会比较结果。

## 答案与原因

1. B — aurons terminé 是先将来时，与未来主句 sortirons 配合。

2. C — 句意应保留动作、时间、否定或条件关系：等我们减少了垃圾之后，我们会比较结果。
