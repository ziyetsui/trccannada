# NA0B · 让声带参与清浊对比

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

用声带振动区分清浊辅音，并把词末节奏读稳。

## 讲解

/p/ 与 /b/、/f/ 与 /v/ 等声音可以在相近的口形下发出，主要区别在声带是否振动。把手轻放喉部读 /f/、/v/，感受后一种声音的振动，不要用“更用力”替代清浊区别。法语的重音通常落在节奏组最后一个发出的音节上；句子不是每个词都像中文四声那样各自起伏。

图句里 gâteau 的 eau 读 /o/，问价格时把 combien 作为询问信息的重点。先读清 gâteau，再把整段 Le gâteau 连起来。词末字母是否发音要以词的读音为准，不能把所有末辅音一刀切地删除，也不能见字母就念。每天挑一对声音交替跟读并录音，先保证对比能听见，再练自然的询问节奏。 最后把疑问语调与发音准确分开检查：语调上扬不能补救元音读错。

- au、eau 常读 /o/；具体词仍需核对。
- 词尾字母与真正发出的最后音节不是一回事。

## 给小朋友的比喻

清浊像同一把小风扇：有时只有气流，有时还开了里面的马达。

## 例句

Le gâteau, c’est combien ? → 这块蛋糕多少钱？

近音钩子：勒，嘎托；塞，孔边（combien）？

脑内电影：蛋糕嘎地托起自己，我凑近看它有多大；手指摸到钱包的小孔，问老板这块蛋糕要多少钱。

发音提示：gâteau /ɡɑto/ 的 eau 读 /o/，词尾不另加音节；combien /kɔ̃bjɛ̃/ 含鼻元音，钩子不替代鼻化。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 读 /v/ 与 /f/，最值得比较什么？

- A. 哪个写得长
- B. 声带是否振动
- C. 是否加汉语声调

### 2. gâteau 的 eau 应按哪种思路读？

- A. 依次念 e、a、u 三个字母名
- B. 把 eau 删掉
- C. 把 eau 当作一个 /o/ 声音组合

## 答案与原因

1. B — /v/ 有声带振动，/f/ 无；字母长度和汉语声调不能解释清浊。

2. C — eau 是常见的 /o/ 组合，不应拆成三个元音；否则词的音节也会改变。

## 一分钟应用

交替读 faux、veau，接着用图句问一次价格；录音时检查是否给 gâteau 多加了音节。

- 不看稿完成：用声带振动区分清浊辅音，并把词末节奏读稳。
- 能用自己的内容造一句，体现：au、eau 常读 /o/；具体词仍需核对。
- 两道题都能说明正确项和一个错误项的差别；图句跟读后能遮文复述。

## 相关学习

先听 → 看图理解 → 分组跟读 → 隐藏文字看图说 → 揭晓回听；隔天、三天后、一周后再回忆。
