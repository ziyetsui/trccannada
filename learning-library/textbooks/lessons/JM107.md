# JM107 · 用 être 介绍自己与定位物品

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

用不同主语介绍两个人职业，再描述三件物品相对桌子的位置

## 讲解

主语换人，être 的形式也要换：je suis、tu es、il/elle est、nous sommes、vous êtes、ils/elles sont。不要只背一串形式，要把每个形式与一个明确主语绑在一起。无修饰的职业通常不用冠词，而 c’est une technicienne 仍保留 une，因为它采用的是识别句架。

位置用 sur、sous、devant、derrière 等词连接参照物。说话先选参照物，再说物品在它哪边；sur 和 sous 不能只靠记汉字近音来区分。职业名词要注意 technicien/technicienne 等形式与读音变化。/ø/ 需要圆唇，/ɛ̃/ 是鼻化元音；ill、tion 等拼写组合有常见读法，也有例外，要在实际词里检验。练习时把六种主语分写在卡片上，随机抽取后说完整句；遇到复数女性群体仍用对应复数变位，而不能因为每人都是女性就沿用单数。用身体指向来检验位置词。

- être 六组人称形式
- 职业裸表语与 c’est 识别句区分
- 位置介词要交代参照物
- technicien 与 technicienne 的鼻化差别

## 给小朋友的比喻

être 像会换制服的服务员，面对不同主语换一套衣服，但工作仍是连接身份或状态。

## 例句

Nous sommes devant la gare. → 我们在车站前面。

近音钩子：“努松”抱着“德旺”灯站在车站门前。

脑内电影：几位旅客抱着一盏灯，在车站正门前等候同伴。

发音提示：nous sommes /nu.sɔm/；devant 结尾鼻化 /ɑ̃/；gare 的 /ʁ/ 不加汉语韵母；中文近音不代替法语发音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 主语为 nous，应选哪个 être？

- A. sommes
- B. sont
- C. êtes

### 2. “在桌子下面”是哪项？

- A. sur la table
- B. devant la table
- C. sous la table

## 答案与原因

1. A — nous 对应 sommes，sont 对应 ils/elles，êtes 对应 vous。

2. C — sous 表示下面；sur 是上面，devant 是前面。

## 输出任务

用不同主语介绍两个人职业，再描述三件物品相对桌子的位置。

- [ ] être 与主语人称一致
- [ ] 能现场指认 sur 和 sous 的位置差别
