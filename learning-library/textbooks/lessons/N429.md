# N429 · 用复合关系代词说明网购选择

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

为虚构网店写六句使用体验，至少两句含不同介词加复合关系代词，并列三项下单前检查。

## 讲解

谈网购时先说明买什么，再说明你凭哪些信息选择。带介词的关系从句常使用 lequel 系列，它与先行词性数配合；à 加 lequel 可缩合成 auquel，de 加 lequel 可形成 duquel。选代词前先确定动词或介词搭配，不能只因先行词是商品就统一用 que。

如果关系从句中介词是 sur，描述网站可说 sur lequel；若表示 avec、pour、sans，也要保留原介词。关系从句不是为了显得高级，而是把购买条件说得准确。比较网页资料与用户评价时标出信息来源，评论不自动等于已核实事实。最终推荐应给可执行的检查步骤，例如确认规格、付款条件和送达方式。

先行词第一次出现时保留完整名称，之后再用关系从句补充购买条件。

- 谈网购时先说明买什么，再说明你凭哪些信息选择。
- 如果关系从句中介词是 sur，描述网站可说 sur lequel；若表示 avec、pour、sans，也要保留原介词。

## 给小朋友的比喻

关系代词像转接头：原来的介词插头要留下，性数决定接头形状。

## 例句

Le site sur lequel je commande affiche clairement les frais de livraison. → 我下单的网站清楚列明运费。

近音钩子：叙尔勒凯勒，利夫雷宗

脑内电影：一位成年买家用放大镜查看电脑上的购物页面，货物与运送费用以清楚的图形分栏呈现。画面不出现文字、标签或字幕。

发音提示：lequel /ləkɛl/；frais /fʁɛ/ 末尾 s 不发音。近音只帮助回忆，法语发音以设备朗读和发音要点核对。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. un site ___ je commande

- A. sur laquelle
- B. dont sur
- C. sur lequel

### 2. 结合完整句，哪项解释准确？

- A. 我下单的网站清楚列明运费。
- B. 我下单的网站把运费完全藏起来。
- C. 我只在没有运送服务的网站下单。

## 答案与原因

1. C — site 阳性单数，用 sur lequel；不要同时叠 dont 与 sur。

2. A — 句意应保留动作、时间、否定或条件关系：我下单的网站清楚列明运费。
