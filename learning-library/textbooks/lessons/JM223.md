# JM223 · 文学人物：从动作细节推断性格

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

为虚构人物写六句画像：两个反复动作、一个物件、一次使役安排、一个性格判断与证据

## 讲解

原第53课通过物件、重复动作和人物反应刻画葛朗台。阅读时先记录钥匙、钱袋、门等物件怎样反复出现，再判断它们如何支持对性格的推断。人物衰弱与执念持续可以形成对比，但“仍然如此”不等于“越来越如此”；程度词和省略结构会影响判断，不能为了鲜明评价随意加重。

文学长句常把谁让谁做什么嵌入 faire 加不定式，读到 se faisait 或 faisait ouvrir 时，需区分安排动作的人与真正执行动作的人。罕见的虚拟式未完成过去时、先过去时可先识别功能并用现代常见结构释义，不把它们当初学口语必须主动使用的形式。人物画像用两项行为证据支撑一个判断，比只罗列贪婪、善良等标签更扎实。

目的关系需明确行动者。Léa ferme la porte pour travailler au calme. 中关门与工作都由 Léa 做，pour 后接不定式；Léa ferme la porte pour que son père puisse se reposer. 中关门者与休息者不同，pour que 引出完整主语并接虚拟式 puisse。afin de 与 afin que 也有类似选择。换成 pour ne pas déranger 时，否定放在不定式前，仍由主句行动者承担；不要把目的误写成已经发生的原因，也不要因省略主语而让读者误以为另一个人在做动作。

- 物件与重复动作构成人物证据
- 仍然与更加的程度区分
- faire + 不定式区分安排者与执行者
- 文学罕见时态以识别为先
- 同一执行者的目的常用 pour/afin de + 不定式。
- 不同执行者用 pour que/afin que + 明确主语 + 虚拟式。
- pour ne pas + 不定式表达避免某事的目的。

## 给小朋友的比喻

人物描写像从脚印认走路习惯，先收集脚印，再下判断，不先画结论。

## 例句

Il garde la clé dans sa poche. → 他把钥匙放在自己的口袋里。

近音钩子：“加尔德”护栏围着口袋里的“克莱”钥匙。

脑内电影：老人把钥匙紧握后塞进有小护栏形装饰的口袋，并不时摸口袋确认。

发音提示：garde /ɡaʁd/；clé /kle/；poche /pɔʃ/；sa 随 poche 阴性而非主人性别；中文近音不代替法语发音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. “他的吝啬并未减轻”能推出哪项？

- A. 吝啬仍然存在，不必表示程度增加
- B. 一定变得更吝啬
- C. 已经完全不吝啬

### 2. Il fait ouvrir la porte par sa fille. 谁实际开门？

- A. 门自己
- B. 一定是他说话的朋友
- C. 他的女儿

### 3. “她关门，好让父亲休息”涉及两个行动者，应选？

- A. Elle ferme la porte pour son père se reposer.
- B. Elle ferme la porte pour que son père peut se reposer.
- C. Elle ferme la porte pour que son père puisse se reposer.

## 答案与原因

1. A — 未减轻只保留原状态，不自动引入更强程度。

2. C — faire 表使役，par sa fille 指实际执行 ouvrir 的人。

3. C — pour que 后保留父亲作从句主语，并用虚拟式 puisse；pour 后不能这样直接放主语加不定式。

## 输出任务

为虚构人物写六句画像：两个反复动作、一个物件、一次使役安排、一个性格判断与证据。 给人物画像补一组目的句：一次同主语用 pour，一次不同主语用 pour que，分别标出行动者。

- [ ] 性格判断有可观察证据
- [ ] 使役句两种角色能还原
- [ ] 目的压缩前后不改变行动执行者
