# NB107 · 交代投诉发生前的事实

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

写一段八十至一百词的虚构服务投诉，按时间列三个事实，用一次愈过去时并提出一个可回答的问题。

## 讲解

投诉或见证中的时间顺序决定了事实是否清楚。愈过去时说明某个过去事件之前已经完成的事，由 avoir 或 être 的未完成过去时加过去分词构成。它不是“特别久以前”的专用时态，而是相对于另一个过去参照点更早；先找参照事件，才能选择正确时态。

写经历时把可观察事实和自己的判断分开：对方先说了什么、自己提交了什么、后来又发现什么。用 pourtant 或 mais 标出矛盾，不需要靠夸张加强力度。教材涉及的机构名称属于材料时代，练习重点是清楚转述与请求解释。遇到不确定动机，用询问或推测表达，不把自己的推论写成已获证实的事实。

- 投诉或见证中的时间顺序决定了事实是否清楚。
- 写经历时把可观察事实和自己的判断分开：对方先说了什么、自己提交了什么、后来又发现什么。

## 给小朋友的比喻

愈过去时像在过去的照片背后再翻出一张更早的照片。

## 例句

Quand je suis revenu, l'agence avait déjà loué le studio. → 我回去时，中介已经把那间单间租出去了。

近音钩子：拉让斯阿韦，代扎卢埃

脑内电影：一个的租赁牌先挂上门，成年人后来返回中介才看见它。画面不出现文字、标签或字幕。

发音提示：avait /avɛ/ 与 loué /lwe/ 分清；déjà 的 j 发 /ʒ/。近音只帮助回忆，法语发音以设备朗读和发音要点核对。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 回去之前已经租出：L'agence ___ le studio.

- A. loue
- B. avait loué
- C. aura loué

### 2. 结合完整句，哪项解释准确？

- A. 我回去以后中介才开始出租单间。
- B. 我回去时中介还没有找到那间单间。
- C. 我回去时，中介已经把那间单间租出去了。

## 答案与原因

1. B — avait loué 是愈过去时，标明比返回更早的完成事件。

2. C — 句意应保留动作、时间、否定或条件关系：我回去时，中介已经把那间单间租出去了。
