# N430 · 把服务差异放到句子焦点

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

写一段餐馆咨询对话，核实账单是否包含服务费；分别用 c'est…qui 和 c'est…que 强调一个不同成分。

## 讲解

讨论小费与服务费时，先分清已计入价格的项目和个人另行给出的金额。读历史文化文章时可以了解习惯差异，但不能把单个例子当成所有地区当前规则。表达重点可用 c'est…qui 或 c'est…que：被强调成分在从句作主语用 qui，作其他常见成分时用 que。

强调句不是简单地在句首加 c'est，再把后面照抄。先写出普通句，找要凸显的是服务质量、某个人还是时间，然后重新连接其余成分。c'est le service qui compte 里 service 是 compte 的主语，因此用 qui。讨论支付安排时用询问来确认，不凭礼貌习惯猜金额，才能把文化理解转成准确交流。

把句子还原成普通语序再检查主谓关系，可以发现大多数强调句错误。

本课另一种强调框架是 Ce qui / ce que / ce dont…, c'est / ce sont…，先用中性 ce 引出“……的事/东西”，再给答案。Ce qui compte, c'est la clarté：qui 是 compte 的主语；Ce que je demande, c'est une facture：que 是 demande 的直接宾语；Ce dont j'ai besoin, c'est d'une explication：dont 对应 avoir besoin de。对照 C'est la clarté qui compte，后者直接突出 la clarté，两种外框不要拼成 Ce que compte。答案是复数名词组时，规范书面表达常用 ce sont：Ce que je préfère, ce sont les visites guidées；不定式答案可用 c'est de+不定式。

- 讨论小费与服务费时，先分清已计入价格的项目和个人另行给出的金额。
- 强调句不是简单地在句首加 c'est，再把后面照抄。
- Ce qui/ce que/ce dont 按从句功能选择；c'est…qui/que 是另一种强调外框。

## 给小朋友的比喻

强调句像手电筒：照向哪一块，那一块就成为大家先看的地方。

## 例句

C'est la qualité du service qui compte pour moi. → 对我来说，重要的是服务质量。

## 练习

### 1. C'est la qualité ___ compte.

- A. qui
- B. que
- C. dont

### 2. 结合完整句，哪项解释准确？

- A. 对我而言，服务好坏完全不重要。
- B. 对我来说，重要的是服务质量。
- C. 顾客的姓名决定服务质量。

### 3. 把 J'ai besoin d'une facture 改为先说“我需要的东西”，正确的是？

- A. Ce que j'ai besoin, c'est une facture.
- B. Ce dont j'ai besoin, c'est d'une facture.
- C. C'est une facture que j'ai besoin.

### 4. “我喜欢的是这些导览”规范书面完成：Ce que je préfère, ___.

- A. ce sont les visites guidées
- B. ce qui les visites guidées
- C. dont les visites guidées

## 答案与原因

1. A — la qualité 在从句作 compte 的主语，因此用 qui。

2. B — 句意应保留动作、时间、否定或条件关系：对我来说，重要的是服务质量。

3. B — avoir besoin de 需要 de，前半由 ce dont 接住，后半保留 d'une facture；不能用直接宾语 que 代替。

4. A — 后半答案是复数名词组，可用 ce sont；ce qui/dont 不能代替系词结构。

## 一分钟应用

写一段餐馆咨询对话，核实账单是否包含服务费；分别用 c'est…qui 和 c'est…que 强调一个不同成分。

补充迁移：先写三句普通句，分别有主语、直接宾语、de补语，再改为 Ce qui/ce que/ce dont…, c'est…；其中一句另改为 C'est…qui/que，解释焦点相同而结构不同。

- 完成并保存本课规定的输出：写一段餐馆咨询对话，核实账单是否包含服务费；分别用 c'est…qui 和 c'est…que 强调一个不同成分。
- 让伙伴根据输出说出人物、动作与条件；若无法复述，标出并改写一处歧义。
- 三种 ce 结构均完整，dont 对应 de；能区分两种强调框架。
