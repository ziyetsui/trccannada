# NA1R08 · 单元8复习：讲回忆，保持背景与事件清楚

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

组织家庭回忆、重逢对话和过去小故事。

## 讲解

回忆需要同时回答“当时是什么样”和“后来发生什么”。先用未完成过去时给出环境、状态或习惯，再用复合过去时组织关键事件。时间标记帮助定位，但不能只看某个词就机械选时态；mariage、école、cinéma 等主题本身也不决定时态。把叙述分成开场、两件事和结束，听者才能在不认识所有词时仍跟上顺序。

原单元应用涵盖家庭博客、老友重逢、广播事件复述和初次观影回忆。本课允许选择不涉及私密生活的一次聚会或旅行，也可明确虚构。图句把玩牌背景与她到达的事件连接，不要求把所有动作都画成瞬间。没有原广播音频时不编造其内容，另写一个小事件请同伴朗读再复述；核对人物、时间、事件，不只核对用了多少过去时。

- 背景与事件配合叙述，不按动作长短机械判断。
- 复述先保人物、时间、关键动作，再补形容词。

## 给小朋友的比喻

回忆像放一段老电影，背景一直在，镜头中的新动作把故事带到下一步。

## 例句

Je jouais aux cartes quand elle est arrivée. → 她到来时我正在打牌。

近音钩子：热，抓韦，哦，卡特，康，诶儿，诶，阿里韦。

脑内电影：我正抓着扑克牌准备出牌，她这时进门到达；手里的牌还悬在半空，我抬头向她打招呼。

发音提示：jouais /ʒwɛ/ 的 -ais 读 /ɛ/；aux /o/；quand elle 可有 /t/ 联诵；arrivée 的 -ée 读 /e/。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. “我们玩牌时，她到了”，事件部分应是？

- A. nous jouions aux cartes
- B. elle est arrivée
- C. aux cartes

### 2. 想完整复述小故事，哪组最重要？

- A. 只记衣服颜色
- B. 只列动词原形
- C. 人物、时间、关键事件与先后

## 答案与原因

1. B — elle est arrivée 推进事件，jouions 描述当时持续背景；aux cartes 不是动词句。

2. C — 这些信息构成故事骨架；孤立颜色或原形列表无法建立完整叙述。

## 输出任务

选择一次真实或明确虚构的聚会，写五句回忆：背景两句、事件两句、结束一句；再口头说给老友听。

- [ ] 不看稿完成：组织家庭回忆、重逢对话和过去小故事。
- [ ] 能用自己的内容造一句，体现：背景与事件配合叙述，不按动作长短机械判断。
- [ ] 两道题都能说明正确项和一个错误项的差别；图句跟读后能遮文复述。

## 相关学习

先听 → 看图理解 → 分组跟读 → 隐藏文字看图说 → 揭晓回听；隔天、三天后、一周后再回忆。
