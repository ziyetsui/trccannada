# NA0D · 把词连成一句话

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

区分联诵与连音，读出辅音群及两位数。

## 讲解

辅音群中的几个辅音要顺着接上，不要在它们中间塞进“呃”。联诵是原本不读的词末辅音在合适环境里出现；连音则是原本就发出的辅音自然接到后一个元音。两者听起来都流畅，机制却不同。限定词和元音开头的名词之间常有必需的联诵，而 et 后面不能因为下一词有元音就随意联诵。

数字最好按意思分块回忆：九十二先想到 quatre-vingt，再接 douze，而不是从一数到九十二。图句练的是识别一个号码，不是计算日期。先看数字说法语，再只听朗读写阿拉伯数字，最后交换顺序。不同地区也有不同数字说法，本课先稳定教材这套用法；设备朗读可帮助对比节奏，但不冒充教材原录音。

- les amis 中的 s 联诵为 /z/；不是所有词末 s 都读。
- quatre-vingt-douze 表示 92；复合数别漏掉后半段。

## 给小朋友的比喻

连音像把本来伸出的手接给下一人；联诵像需要时才从口袋伸出一只手。

## 例句

C’est le numéro quatre-vingt-douze. → 这是九十二号。

近音钩子：塞，勒，纽梅罗；卡特儿，万，杜兹。

脑内电影：牛奶盒上的号码让小卡车停下：九十二号到了；九个气球和两只鸭子守在门口，帮我牢牢记住号码。

发音提示：quatre-vingt-douze /katʁəvɛ̃duz/ 中 vingt 的鼻音不要读成汉语“温特”；douze 末尾 /z/ 发出。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. les amis 与 une amie 的连接分别是？

- A. 都一定是新增辅音的联诵
- B. 前者联诵，后者连音
- C. 前者连音，后者联诵

### 2. quatre-vingt-douze 是哪个号码？

- A. 82
- B. 90
- C. 92

## 答案与原因

1. B — les 的 s 原来不读，联诵时出现 /z/；une 的 /n/ 本来就读，再接 amie。

2. C — quatre-vingt 是八十，再加 douze 十二，得到九十二。

## 一分钟应用

随机写 72、81、92，分别读出；再把 les amis、une amie 接成自然语流，说明各是哪种连接。

- 不看稿完成：区分联诵与连音，读出辅音群及两位数。
- 能用自己的内容造一句，体现：les amis 中的 s 联诵为 /z/；不是所有词末 s 都读。
- 两道题都能说明正确项和一个错误项的差别；图句跟读后能遮文复述。

## 相关学习

先听 → 看图理解 → 分组跟读 → 隐藏文字看图说 → 揭晓回听；隔天、三天后、一周后再回忆。
