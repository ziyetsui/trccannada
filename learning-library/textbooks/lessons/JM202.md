# JM202 · 读懂故事里的简单过去时

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

写一个三句微型故事，分别承担背景、推进事件、回溯更早事件；再口头改写推进句

## 讲解

文学叙事和历史文本常用简单过去时推动事件，尤其常见第三人称形式。il entra、ils partirent、il fut、il eut 等应先练识别与还原原形，不必立刻把所有人称都当口语高频形式背熟。用口头复述故事时，很多这类事件可以改用复合过去时，但书面作品本身的叙述节奏仍值得辨认。

简单过去时不独自承担整段故事：未完成过去时可以描述布景、状态与习惯，愈过去时交代主事件之前已完成的动作。不能把动词在句中出现顺序当成真实时间顺序，回忆段落可能在后文才补早发生的事。原课还总结主从句时态配合，应先确定参照点与同先后关系，再观察作者选用的具体时态。

- 简单过去时以阅读识别为先
- fut/eut 等形式单独辨认
- 与 imparfait、plus-que-parfait 合作构成叙事
- 口头复述可改用复合过去时

## 给小朋友的比喻

简单过去时像故事的一格格翻页按钮，背景没有每按一次按钮就全部重画。

## 例句

Le voyageur entra dans la maison. → 旅人走进了屋子。

近音钩子：“昂特拉”入口地毯迎接旅人。

脑内电影：一位成人旅人踩上门口地毯，推开门走进屋子，故事镜头记录进入的一刻。

发音提示：entra /ɑ̃.tʁa/；voyageur /vwa.ja.ʒœʁ/；maison /mɛ.zɔ̃/；中文近音不代替法语发音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 故事中 il fut 的原形是？

- A. faire
- B. fuir
- C. être

### 2. 把 il entra 改成日常口头复述通常可用？

- A. il entrait 永远等义
- B. il est entré
- C. il a entre

## 答案与原因

1. C — fut 是 être 的第三人称单数简单过去时，不是 faire 或 fuir。

2. B — entrer 的不及物进入用 être，复合过去时为 est entré；imparfait 会改变视角。

## 一分钟应用

写一个三句微型故事，分别承担背景、推进事件、回溯更早事件；再口头改写推进句。

- 能识别原形而不只猜中文意思
- 三种过去时各有叙事任务

## 相关学习

先听 → 看图理解 → 分组跟读 → 隐藏文字看图说 → 揭晓回听；隔天、三天后、一周后再回忆。
