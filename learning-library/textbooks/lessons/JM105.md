# JM105 · 说一件物品的名称与归属

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

拿两件自己的物品，先说是什么，再说明是谁的，并为其中一件加颜色

## 讲解

首次介绍一件物品，用 un 或 une 加名词；当你和对方已能确定是哪件物品时，常改用 le 或 la。阴阳性是名词的语法属性，物品没有生理性别也要连冠词一起记。表示“某人的物品”用物品加 de 加人名，顺序与汉语相反；不要把汉语“的”前后位置直接搬过去。

颜色可跟在名词后作修饰，也可放在 être 后说明状态；注意 verte 与 vert 等性别形式。语音练 /y/ 时舌位接近 /i/，嘴唇收圆；/o/ 保持一个稳定元音。鼻化元音的气流经过鼻腔，但不是在元音后另补一个清晰 n。原书鼻元音图符有缺失，应靠可靠示范与标准符号校准。同一物品再次出现时，把它与第一次引入的说法并排比较，说明听者为何此刻已经知道你指哪一个。

- un/une 与 le/la 区分首次引入和确指
- de 的所属顺序是物品在前
- /y/ 圆唇前元音，鼻化不是加 n

## 给小朋友的比喻

冠词像物品的标签：第一次拿出“一件”，第二次指向“那一件”。

## 例句

C’est le vélo de Léa. → 这是莱娅的自行车。

近音钩子：“塞勒”车铃属于“莱娅”。

脑内电影：莱娅正握着自行车车把，朋友指着她的车铃确认这辆车的主人。

发音提示：vélo 为 /ve.lo/；de 通常读 /də/；Léa 的两个元音分成两音节；中文近音不代替法语发音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 说“安娜的包”选哪项？

- A. Anna de le sac
- B. le Anna sac
- C. le sac d’Anna

### 2. /y/ 应怎样练？

- A. 一定要读成两个音节
- B. 保持 /i/ 的舌位并收圆嘴唇
- C. 在 /u/ 后加一个 n

## 答案与原因

1. C — 所属关系把物品放前面，de 遇 Anna 省音为 d’。

2. B — /y/ 是一个圆唇前元音，不是复合音或鼻辅音。

## 输出任务

拿两件自己的物品，先说是什么，再说明是谁的，并为其中一件加颜色。

- [ ] 每个名词连同阴阳性记忆
- [ ] 归属表达不会颠倒词序
