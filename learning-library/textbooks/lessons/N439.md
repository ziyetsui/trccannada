# N439 · 说明文化开放活动的目标

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

设计一次包容性开放日，写一百词邀请，包含两项具体可参与安排，并用 pour que 说明各自目的。

## 讲解

介绍开放日要分清哪些场所开放、哪些人能参加，以及特别安排服务于谁。无障碍导览不是一句“欢迎所有人”就完成，需要具体说明触觉、语言或路线安排。表达目的时，pour 加不定式通常适合同一主语，pour que 加分句可引出不同执行者，并采用虚拟式。

afin que 与 pour que 都可说明目的，但目的不保证实现。应把“为了让更多人参与”与“已经有更多人参与”分开表达。活动说明中的历史年份和举办范围用于理解资料，不自动成为今年安排。自拟邀请时提供时间、预约条件与联系方式，并把需要读者采取的一步行动写在结尾，让介绍真正能够用于出行。

- 介绍开放日要分清哪些场所开放、哪些人能参加，以及特别安排服务于谁。
- afin que 与 pour que 都可说明目的，但目的不保证实现。

## 给小朋友的比喻

目的像门外的坡道：希望大家进来，还要说清坡道为谁铺、怎样走。

## 例句

Le musée propose des visites tactiles pour que chacun puisse participer. → 博物馆提供触觉导览，让每个人都能参与。

## 练习

### 1. pour que chacun ___ participer

- A. puisse
- B. peut
- C. pourra

### 2. 结合完整句，哪项解释准确？

- A. 博物馆设置触觉导览，是为了阻止公众进入。
- B. 博物馆提供触觉导览，让每个人都能参与。
- C. 每位参观者都必须独自制作展品。

## 答案与原因

1. A — pour que 表目的，后用虚拟式 puisse，而非直陈式 peut/pourra。

2. B — 句意应保留动作、时间、否定或条件关系：博物馆提供触觉导览，让每个人都能参与。
