# JM102 · 问是不是，并说职业

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

为两位虚构同事各写一个职业句，再用 est-ce que 向搭档确认

## 讲解

想确认身份，可以把 est-ce que 放到完整陈述句前。它本身已经标记疑问，后面保留主语加动词的顺序，不必再把主语倒装。先说陈述句，再加问句框架，比一边选词一边换顺序容易。回答 oui 后补一个完整短句，能让对方听清你确认的究竟是什么。

用 il est 或 elle est 直接说明普通职业时，职业名词前通常不加冠词；用 c’est 来识别人则常带 un 或 une。journaliste 男女词形相同，不能仅凭词尾猜性别。发音上区分 /ʃ/ 与 /ʒ/：嘴形相近，后者声带振动；/œ/ 要圆唇，别把 chercheur 拆成几个汉字的独立重音。对职业提问时，应区分“这是谁”和“他做什么工作”；身份确认与职业询问需要不同答案，回答不能只重复姓名。

- est-ce que 后保持陈述词序
- être 后无修饰的职业常省冠词
- /ʃ/ 与 /ʒ/ 对比声带振动

## 给小朋友的比喻

疑问框架像门口一块问号牌，牌子立好，屋里的家具顺序不用重摆。

## 例句

Elle est journaliste. → 她是记者。

近音钩子：“艾莱”拿着“茹纳”新闻本。

脑内电影：一位女士拿着像小日记本的新闻本，在街头举麦克风采访。

发音提示：journaliste 为 /ʒuʁ.na.list/；/ʒ/ 有声带振动，词尾 te 不另添一个元音；中文近音不代替法语发音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 确认她是不是记者，哪句规范？

- A. Est-ce qu’est-elle journaliste ?
- B. Elle est-ce que journaliste ?
- C. Est-ce qu’elle est journaliste ?

### 2. 单纯说“他是演员”选哪句？

- A. Il acteur est.
- B. Il est acteur.
- C. Il est un acteur de.

## 答案与原因

1. C — est-ce que 已引导疑问，后面不再倒装。

2. B — 单纯说明职业用 Il est acteur。Il est un acteur de. 的主语和动词顺序本来正常，但 de 后缺必要补语，整个表达未完成；Il acteur est 的主谓顺序才有问题。
