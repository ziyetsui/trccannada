# JM219 · 人口议题：趋势、比例与条件结论

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

自设两年图书馆访客数据，用三句写趋势，另写一个带明确条件的未来推演，并注明数据为虚构

## 讲解

原第49课借人口与家庭讨论趋势。阅读时先把数据的时间、对象和计量单位圈出来：人数、比例、每人的平均值不是同一件事；某年的降低也不自动意味着今天仍降低。描述趋势可用 augmenter、diminuer、la hausse、la baisse，但数值变化和作者对变化的评价应分开记录。

家庭词组也会因结构改变意思：des familles nombreuses 常指子女较多的家庭，而 de nombreuses familles 指许多家庭。条件式可提出“若趋势继续可能怎样”的推演，不能把它改成已经发生的结论。原课中的统计有明确历史背景，本课不更新也不延伸为当代人口判断；练习使用自行设定的小型数据，任务是准确复述方向与条件，保留不确定性。

不精确数量仍要区分词类。plusieurs visiteurs、quelques visiteurs 都直接限定复数名词，表示多个或一些，不给固定数目；quelques-uns 则独立代替前文已知的一群对象，后面不直接再接 visiteurs，阴性群体可用 quelques-unes。选几个对象出来时可说 quelques-uns des visiteurs。environ trente personnes 中 environ 修饰数值，约三十人；vers dix-huit heures 中 vers 表大约时刻，也可表空间方向。不能把 environ 和 vers 当成能在所有名词前自由替换的一对同义词。

- 趋势词与评价词分开
- familles nombreuses 与 nombreuses familles 意义不同
- 条件推演不是既成事实
- 数字须带时间、对象与单位
- plusieurs/quelques + 复数名词；quelques-uns/quelques-unes 独立代指。
- quelques-uns des visiteurs 表部分访客。
- environ + 数量；vers + 大约时刻，vers 另有空间方向义。

## 给小朋友的比喻

趋势像温度计的两次读数，要先看刻度、日期和测量对象，才能说升降。

## 例句

Le nombre de visiteurs diminue. → 访客人数在减少。

近音钩子：“迪米纽”变小的计数球记录访客。

脑内电影：展馆门口成人管理员看着一个逐渐变小的计数球，进门的访客比前一时段少。

发音提示：nombre /nɔ̃bʁ/；visiteurs /vi.zi.tœʁ/；diminue /di.mi.ny/，主语中心 nombre 为单数；中文近音不代替法语发音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. de nombreuses familles 意思是？

- A. 唯一一个家庭
- B. 许多家庭
- C. 每个家庭都很多孩子

### 2. Le nombre de visiteurs 后动词单数还是复数？

- A. 通常单数，与 nombre 配合
- B. 一定复数，与 visiteurs 配合
- C. 不能接动词

### 3. 前文已提到一群访客，“其中一些离开了”应选？

- A. Quelques visiteurs-uns sont partis.
- B. Quelques sont partis.
- C. Quelques-uns sont partis.

### 4. 用近似数量和近似时刻补全 ___ trente personnes arrivent ___ dix-huit heures.，最自然的是？

- A. Environ / vers
- B. Quelques-uns / environ
- C. Plusieurs / quelques

## 答案与原因

1. B — 前置 nombreuses 强调家庭数量；familles nombreuses 常描述多子女家庭。

2. A — 名词组中心是 le nombre，de visiteurs 是补语。

3. C — quelques-uns 是可独立作主语的代词；quelques 通常需限定后面的复数名词，不能直接这样独立使用。

4. A — environ 修饰 trente 这一人数，vers 引出大约十八点；代词 quelques-uns 不能直接限定 trente personnes。

## 输出任务

自设两年图书馆访客数据，用三句写趋势，另写一个带明确条件的未来推演，并注明数据为虚构。 给虚构数据补一句 environ 人数、一句 vers 时刻，再用 quelques-uns 回指其中部分访客。

- [ ] 数据单位与时间齐全
- [ ] 推演未写成已经证实的结果
