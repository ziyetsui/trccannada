# JM212 · 核对分词配合，压缩先完成动作

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

写两句结构不同的代词式过去句并解释配合，再把一个先完成动作压缩为 ayant + 分词

## 讲解

过去分词配合先看结构：être 的常见不及物复合时态通常随主语，avoir 则查看是否存在前置直接宾语。代词式动词不能只因为助动词为 être 就一律随主语，要判断反身代词是否直接宾语。elles se sont parlé 中 se 是间接宾语，不触发配合；elles se sont lavées 中 se 是直接宾语，情况不同。

复合分词由 ayant 或 étant 加过去分词构成，可压缩一个更早完成的动作，如 ayant terminé。其逻辑执行者必须清楚，通常与主句相关名词一致；若压缩后导致“文件完成了工作”这类错配，就应恢复成完整从句。阅读新闻或叙事时，先识别这块压缩信息在交代原因还是先后，再用直白句子展开，有助于避免只顾词尾而丢失意思。

还应把固有代词式动词与间接宾语型相互动作区分开。se souvenir de 表示记得，Elle s’est souvenue de son rendez-vous. 的 souvenue 按阴性单数主语配合；不能因后面有 de 就认定 se 是间接宾语并删掉 e。相对地，Elles se sont parlé. 的 parler à 明确让 se 承担间接对象，因此 parlé 不按主语加 es。分词也可作形容词说明状态：将 Les portes sont fermées. 理解为门处于关闭状态时，fermées 与阴性复数 portes 配合。具体语境也可能把该句理解为被动结构，但两种分析都不能忽略主语的性数。

- avoir 配合看前置直接宾语
- 代词式分词须分析 se 的功能
- ayant/étant + 分词表示先完成
- 压缩结构需明确逻辑主语
- 固有代词式 se souvenir 的分词通常与主语配合：elle s’est souvenue。
- 互相说话 se parler 中 se 是间接对象，elles se sont parlé 不加 es。
- 分词作状态形容词仍按名词性数变化：les portes sont fermées。

## 给小朋友的比喻

配合像核对包裹收件栏：先找真正的直接对象，再决定分词贴哪张标签。

## 例句

Ayant terminé son travail, Léa est partie. → 完成工作后，莱娅离开了。

近音钩子：“艾扬”完成章盖在工作纸上，莱娅拿包离开。

脑内电影：莱娅给工作文件盖完工章，接着提包从办公室离开，章与离开的动作连在同一场景。

发音提示：ayant /ɛ.jɑ̃/；terminé /tɛʁ.mi.ne/；partie 的 e 表阴性不另发音；中文近音不代替法语发音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. Elles se sont parlé. 为什么 parlé 不加 es？

- A. se 是 parler à 的间接宾语
- B. 所有 elles 都不配合
- C. parler 没有过去分词

### 2. Ayant terminé..., Léa est partie. 谁完成工作？

- A. travail 自动作主语
- B. 说话者必定是 je
- C. Léa

### 3. 哪组分词同时符合本课三种结构？

- A. Elle s’est souvenu... / Elles se sont parlées. / Les portes sont fermé.
- B. Elle s’est souvenue... / Elles se sont parlées. / Les portes sont fermés.
- C. Elle s’est souvenue... / Elles se sont parlé. / Les portes sont fermées.

## 答案与原因

1. A — 互相说话的 se 对应 à quelqu’un，非前置直接宾语。

2. C — 压缩分词动作与主句 Léa 相连，两个动作由同一人承担。

3. C — se souvenir 是固有代词式，此处 souvenue 随 elle；se parler 的 se 是间接宾语，不触发 parlé 的 es；fermées 描述阴性复数 portes 的状态。
