# NA135 · 谈改变，用如果连接条件与后果

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

用 si 加现在时表达现实可行的条件。

## 讲解

讨论装修或计划改变时，si 引出条件：如果条件成立，后面会怎样。本课练现实可行的条件，si 从句用现在时，主句可用现在时、将来时或命令式；不能因为整句谈未来就把 si 后也机械变成将来时。先用中文想清“要满足什么”和“满足后做什么”，再各写一个短分句，会比直接翻长句更稳。

图句比较两间厨房的明亮程度，可作为提出改变的依据，但比较本身不是条件句。plus…que 表更……，moins…que 表不如……，aussi…que 表一样……。迁移时用自己新造的一条条件接上实际行动，例如天气好就出门；不需要为了练句型虚构真实购买决定。写完把条件与结果互换读，检查逻辑是否仍成立，语法正确也要说得通。

在本课这种面向未来的计划里，si 与 quand 要分开处理。Si nous achetons ce logement, nous repeindrons le salon：购买尚是条件，si 后用现在时 achetons。Quand nous aurons les clés, nous repeindrons le salon：把拿到钥匙作为未来时间定位，quand 后可用简单将来时 aurons。这里 aurons 是 avoir 的简单将来时，不是“已经拥有”的复合形式。不能把 si 从句照搬成 si nous achèterons，也不能因为英语时间从句常用现在时就强制法语 quand 后只用现在时。先判断在说“如果成立”还是“到那个时候”，再选择结构；quand 的语法选择也不等于保证事件必然发生。

- 现实条件 si + 现在时，后面结果可用简单将来时。
- plus/moins/aussi + 形容词 + que 表比较。
- 未来计划：si + 现在时表达条件；quand + 简单将来时定位未来时点。

## 给小朋友的比喻

条件句像门铃开关：先按下条件，后面的灯才会亮；两边都有各自的位置。

## 例句

Votre cuisine est plus claire que la mienne. → 您的厨房比我的明亮。

近音钩子：沃特儿，屈伊兹讷，诶，噗吕，克莱儿，克，拉，米耶讷。

脑内电影：您的厨房亮得像开了小太阳，我的厨房在对面暗一点；两只小锅互相照照，您的那边明显更明亮。

发音提示：cuisine /kɥizin/ 留意 /ɥ/ 与 /z/；claire /klɛʁ/ 的 cl 不加音节；la mienne /la mjɛn/ 不是鼻元音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. 哪句符合本课现实条件结构？

- A. Si tu viendras, nous dînerons ensemble.
- B. Si tu viens, nous dînerons ensemble.
- C. Si tu venir, nous dînerons ensemble.

### 2. “比这间更明亮”关键结构是？

- A. plus clair que cette pièce
- B. plus clair de cette pièce
- C. aussi plus clair cette pièce

### 3. 谈未来拿到钥匙后整理书房，哪组符合本课结构？

- A. Si nous aurons les clés, nous rangerons le bureau.
- B. Quand nous avons eu les clés demain, nous rangerons le bureau.
- C. Quand nous aurons les clés, nous rangerons le bureau.

## 答案与原因

1. B — si 从句这里用现在时 viens，结果可用将来时 dînerons。

2. A — 比较级是 plus + 形容词 + que；de 不连接这类比较对象。

3. C — quand 定位未来时点，可接简单将来时 aurons；条件 si 后此处用现在时 avons，不能用 aurons；第二项过去形式与 demain 冲突。

## 一分钟应用

为虚构住房写四句改变计划：一句用比较级说明需要改变的地方；一句 Si nous avons assez d’argent… 给出有条件的装修结果；一句 Quand nous aurons les clés… 安排未来动作；最后一句说明先后次序。续写内容必须是你自己的，不把比较句当作已经完成条件句任务。

- 不看稿完成：用 si 加现在时表达现实可行的条件。
- 能用自己的内容造一句，体现：现实条件 si + 现在时，后面结果可用简单将来时。
- 两道题都能说明正确项和一个错误项的差别；图句跟读后能遮文复述。
- 能独立使用比较、si条件和quand未来时间定位三种结构；指明哪一项仍取决于条件。
