# JM226 · 观点文章：他人看法、反驳与结论

> 本站原创中文辅助微课。原书全文保留本机；设备合成朗读不是原录音。

## 学完能做什么

以花园或一顿饭为例写六句观点文：他人看法、你的立场、两个理由、一个假设、结论

## 讲解

原第56课讨论劳动与生活所需之物，开篇先摆出某种关于自然与过去的看法，再展开反驳。阅读必须标明观点是谁的：作者先介绍一个论点，不等于赞同它。en réalité、en effet、à plus forte raison 等标志分别引导纠正、说明和递进，加强理由的方式不同，不能全部翻成“其实”。

条件句可构造一个反事实世界来检验论点，例如假设没有某项人类活动会怎样；这种思想实验不是已经观察到的事实。ce que 帮助把“我们得到的东西”和“我们希望的东西”变成可比较的名词性块。原书的历史判断和科学例子要放回其写作语境，本课聚焦论证结构，迁移选择日常园艺或做饭，写出观点、理由、例子与结论之间的连接。

结果表达把程度与后果连接起来：Le sac est si lourd que je ne peux pas le porter. 用 si 加形容词；Il travaille tellement qu’il oublie l’heure. 用 tellement 修饰动作；Il a tellement de dossiers qu’il reste tard. 则需 de 连接名词。这里的 si 是程度副词，不是引出假设的“如果”。trop lourd pour être porté 表超过可实现某动作的程度；说 Je suis trop fatigué pour continuer. 时，疲惫与继续的执行者相同。若说 Ce dossier est trop lourd pour que je le porte.，结果从句改用 pour que 加虚拟式，不能把人和文件的动作角色混掉。

- 区分引述观点与作者立场
- en réalité/en effet/à plus forte raison 各有作用
- 反事实思想实验不等于事实报告
- ce que 把内容变成名词性结构
- si + 形容词/副词 + que；tellement + 动词关系或 tellement de + 名词 + que。
- 程度结果中的 si 不等于条件连词 si。
- trop...pour + 不定式表达程度导致难以实现的结果；不同执行者可用 pour que + 虚拟式。

## 给小朋友的比喻

论证像搭桌子：观点是桌面，理由是桌腿，例子检验桌腿是否真的撑得住。

## 例句

Le jardin dépend du travail humain. → 花园依赖人的劳动。

近音钩子：“德庞”吊篮靠人的劳动绳索支撑。

脑内电影：成人在花园浇水、修剪，一只吊篮靠人工拉起的绳索稳定，植物因此得到照料。

发音提示：dépend /de.pɑ̃/ 末 d 不读；travail /tʁa.vaj/；humain /y.mɛ̃/，h 不发音；中文近音不代替法语发音。

近音只帮助提取记忆，准确声音先听法语，再回听核对。

## 练习

### 1. “文件太多，以至于我需要帮助”应选哪句？

- A. J’ai tellement dossiers que j’ai besoin d’aide.
- B. J’ai tellement de dossiers que j’ai besoin d’aide.
- C. J’ai si dossiers pour j’ai besoin d’aide.

### 2. Je suis trop fatigué pour continuer. 最准确的理解是？

- A. 我为了继续而特意变疲惫
- B. 如果我疲惫就证明已经继续了
- C. 疲惫程度超过我能继续的限度

## 答案与原因

1. B — tellement de + 复数名词表达数量程度，que 引出结果从句；不能漏 de，也不能用 si 直接限定 dossiers。

2. C — trop...pour 表程度妨碍某动作实现；pour continuer 在这里不是为疲惫寻找目的。

## 一分钟应用

以花园或一顿饭为例写六句观点文：他人看法、你的立场、两个理由、一个假设、结论。 给观点短文补两种结果结构：si 或 tellement…que 一句，trop…pour 一句，并标明结果是否真的发生。

- 每个观点有持有者
- 例子能支撑理由而非只重复结论
- 能区分程度结果、目的与假设
