# 三语平行语料初步核验 D01

日期：2026-10-11。性质：本次独立执行的探索性描述统计，检查研究问题与指标是否对应；不作为三语普遍规律或认知差异的证明。

## 数据与可复现性

采用 Universal Dependencies 的 English-PUD、French-PUD、Chinese-PUD，固定 tag `r2.16`。三语各1,000个对齐单元；本次核对了全部 `sent_id` 的顺序完全一致。官方 README 提醒，一个对齐单元偶尔可能实际包含两个句子，因此表中“句子”应理解为树库句段。

官方说明：前750句原始语言是英语，后250句原始语言包括德、法、意、西，经英语中转译向其他语言。文本来自新闻和维基百科，通常只抽取每个文档少量句子，非连续篇章。于是它适合控制大致命题内容，不适合直接研究完整话题链，也不是三语独立自然产出的可比语料。

来源：[English-PUD](https://universaldependencies.org/treebanks/en_pud/index.html)、[French-PUD](https://universaldependencies.org/treebanks/fr_pud/index.html)、[Chinese-PUD](https://universaldependencies.org/treebanks/zh_pud/index.html)。本地保留三个固定版本 README、CoNLL-U 文件、[下载 URL 与 SHA-256](corpus/manifest.json)。许可为 CC BY-SA 3.0；作者与贡献者信息见各 README。网页当前版本可能已更新，本报告计算版本由本地 manifest 确定。

执行：

```sh
python3 docs/scripts/analyze_pud.py
```

[脚本](../scripts/analyze_pud.py)仅读取整数 ID 的句法词，忽略多词词元行和空节点；`syntactic_words` 包含标点。各指标按“一个句段至少出现一次符合条件的词/关系”计数，不是结构出现总次数。

## 指标定义及解释限制

**被动相关标注。** 依存关系字符串含 `:pass`，或 FEATS 含 `Voice=Pass` 即命中。它是便于筛查的操作定义，不是完整被动构式识别器。可能漏掉法语某些 `se faire`、中动式和汉语无标记受事句，也可能纳入形容词性或状态分词。不能把24.2%直接称为“英语事件被动率”。

**代词。** `UPOS=PRON`，包括不同功能的代词。显式代词不同于回指次数；不能测量汉语零回指，也不能由法英近似的数字推出回指系统相同。

**连接与从属。** `SCONJ` 是词类；`advcl` 是依存关系，二者不互相等价。汉语 SCONJ 很少但 advcl 较多，正好展示为什么“连接词频率”不能直接衡量“逻辑明确程度”。不同树库怎样分词、怎样标注汉语连动/状语及关联词，会直接影响结果。

**关系从句。** `acl:relcl` 是树库标签，不等于三语都具有同样形式的关系代词。汉语“的”字修饰及相关分析会扩大该标签范围，不能将36.4%与英法比例当成纯粹自然使用差异。

**形态特征。** `Tense/Gender/Number` 是标注信息，不测量语义表达能力。汉语 Tense=0不表示不能表达时间；英语 Gender 往往与特定代词有关，不等于法语名词语法性。英法 Number 达100%也可能由一个复数或单数特征触发，不能表示每个词都标数。

**句法词总数。** 法语比英语多约16.7%，但包含冠词、介词、代词拆分、标点等因素；中文分词粒度又不同。这里只报告长度，不据此评价简洁程度，更不用汉字数与法语空格词直接比。

## 人工回查的两个诊断点

1. `n01020004`：英语为 *Previously the jets had only been seen by bloggers.*；法语也采用被动组织，汉语把见到飞机的人放到前景。这说明同一命题内容可能改变语态与信息结构，需人工辨别翻译对应，而不是一见标注不同就判数据错误。
2. `n01016019`：英语“最适于从某事件获利”的分词形式会触发被动相关标注，未必是本研究要数的事件被动。另有 `n01013005` 的中文词义对应值得复核，提示平行文本本身也可能有翻译瑕疵。

这里只做了少量诊断性人工回查，**没有**完成被动、从属或回指的全样本人工校验，也没有计算识别准确率。

## 能支持的研究发现

- 这份对齐样本的形式标签分布不同，适合找到后续人工研究的案例。
- 同一“语言倾向”用不同指标衡量会出现不同排序，因此原书宏观维度需要明确操作定义。
- 译文会改变语态、显性成分和句法包装，平行语料能揭示转换，但不能直接代表原生写作偏好。

尚不能支持：普遍的被动频率排名、语言复杂度排名、主体/话题重要性排名，或任何民族思维/理性程度排名。本轮不做显著性检验；同一句段的语言版本是配对观察，即使后续计算统计显著性，也必须先解决标注可比性与翻译方向的问题。
