## 一课的内容标准

先写“学完能做什么”，用真实交际任务限定内容；随后给中文解释、直观比喻、法语例句、练习、答案与理由、一分钟应用和来源。说明原书位置与本次原创辅助的区别。

每个例句都同时保留：稳定 ID、准确法语、中文意思、近音钩子、脑内电影、发音提示和对应图片。难词先分块，最后必须回到完整句子；近音不替代法语元音、鼻音、连读和节奏。

具体可用比抽象解释更重要。例如学礼貌请求时，练点餐、订房、留口信；讲清对象、数量、意图与语气。每个答案都解释为什么，并给可以立即开口的应用任务。

## 学习交互的基准

沿用现有五步流程，不以新增资料为由重做原课程导航：

1. 先听设备法语朗读，建立准确声音目标。
2. 看一句对应的一幅大图，理解真实意思。
3. 阅读声音钩子与脑内电影，自己解释它们怎样关联。
4. 分组跟读后隐藏答案，看同一张图自己说。
5. 揭晓法语、回听核对；之后隔一会、隔天再试，并换一个情景表达。

回忆时一起隐藏法语、翻译和会泄露答案的近音提示。图片继续可见，主动揭晓由学习者控制。播放过、看过图、点过按钮均不自动等于掌握。

保留搜索、课程筛选、单词点击、法语声音选择、慢读、停止、学习标记、复习和明暗模式。进度只存在本机浏览器；存储不可用时页面仍能使用。合成语音标为设备朗读，不能冒充原书 CD 或考试原音；没有法语声音时不退回英语声音。

## 每张图怎样才合格

采用一个完整、容易描述的生活场景，声音钩子必须参与目标动作。先保住真实句意，再决定保留哪个钩子。大主体、清晰手势和视线，让“谁在做什么”一眼可见。

视觉基准是暖白底、深色手绘轮廓、少量青绿和橙色、平涂绘本质感、成年人物、横向 3:2。不把整句、中文谐音和音标烧进图片；文字留在可选择的 HTML。学习对象确为拼写、数字或时间时，允许必要的实体字母/数字道具，逐张校对。

长句使用共同情境；避免多格漫画、无关物件堆砌和装饰盖过目标。数量、否定、人物关系、时间先后和请求意图都是硬约束。

最终版本的修订是可复用的验收案例：

| 句意 | 易出错处 | 最终约束 |
|---|---|---|
| 六点半 | 指针不清、物件数量混淆 | 两排各三个瓜，数字钟 6:30 |
| 三种语言 | 多出第四条语音形状 | 三条可分辨的语音带 |
| 三人房 | 床被遮挡，看起来只有两张 | 三位旅客、三张床、三个枕头 |
| 四天前/四天 | 多出第五个记号 | 四辆卡车或四个明确日历标记 |
| 点汤与茶 | 乌龟道具被误读成菜肴 | 乌龟参与托盘动作，点单对象清楚 |

先审一个代表样本，再批量生成；逐课看总览，遇到数量、拼写、时间和歧义看大图。每次修订保留原 ID，增加图片版本并记录原因。

## 从资料到备考内容

官方信息、公开样题、第三方训练与本站原创热身要明确标识。资源写明机构、原始链接、适用技能、使用步骤、核验日期与核验限制。读不到原文时如实写“由官方推荐，正文未独立核验”。

TCF Canada 内容优先解释如何练习听、说、读、写。共享的 TCF 资料要注明适用范围；通用 TCF 的语法模块或 90 分钟模拟不能包装成 Canada 四项完整模拟。原有 A1 图句只能称基础热身，不能据此标注 B2、NCLC 或预测考试分数。

使用独立分支和 worktree，先确认开发基线、未推送提交和原功能去向。这个项目实际发布分支是 `publish/website`，不能仅依据默认分支猜测。

修改源模板后重建，检查入口仍在。图片必须绑定精确原句、翻译、钩子与脑内电影；覆盖校验、路径检查、图片解码与校验值要能发现缺图和错配。图片相对路径、懒加载，损坏时保留可读文字。

新的生成任务遵循当次可用工具及用户授权；历史供应商/模型仅作为溯源信息。密钥、私有原书和任务状态不进入公开站点。保存完整 prompt、模型与参数、稳定 ID、输出路径及校验值；超时恢复已有任务，避免重复付费提交。

交付前核对：图句对应、回忆隐藏、原句法语朗读、无语音、图片失败、手机溢出、明暗模式、离线/子路径、现有功能回归。检查实际静态文件，不能只看构建成功。验证行为可用与学习效果有效是两种不同结论。
