# TCF Canada 备考入口与 Oxford 学习方法沉淀

2026-10-27。用户选择独立备考页，并授权自行决定细节、开发、验证、push 和创建 PR；保留主仓库。

## 目标与范围

在学习库首页添加入口，新增 `learning-library/tcf-canada/`。提供官方考试概览、官方样题入口、听说读写训练方法和可执行的练习路线。注明来源、核验时间及资料适用范围。以公开原站链接和原创中文导航组织资料。

用户补充要求：回看既有 spec 和 prompt，沉淀最佳实践；特别喜欢 Oxford 起飞最后一版的功能和图像。

## 依据与实现决定

- 主仓库 `site` 保留，从 `origin/publish/website` 的 c02edeb 创建 `feat/tcf-canada-prep`。当前聊天位于另一个非 Git 目录，原生创建工具返回 Not a git repository，使用目标仓库的 git worktree；放在项目父目录的 `.worktrees/`，不改主仓库文件。
- 既有 spec 文件为空。方法依据是可追溯的历史用户消息、`visual-memory-design.md`、最终图片 manifest、实现与验收记录，不补写成旧 spec 原文。
- 优先 FEI、TV5MONDE 和 FEI 推荐的 RFI。FEI 已通过网页阅读后端获取正文；直接抓取受防护。RFI 仅核实 FEI 的推荐及链接，未独立读取正文，不声称试用或题量已核验。
- 备考页复用现有视觉语言，加入三张 Oxford 图片的原句热身卡；保持原句、中文、谐音、画面与稳定 ID 一致。标签明确为基础热身，官方题目从 FEI 入口练习。沿用听音、看图、主动回忆、回听核对。
- 浏览器语音属于设备合成朗读；没有法语声音时停用朗读按钮，正文、图片和来源照常可用。文本全部静态呈现，禁用 JS 仍可读。

## 方案取舍

用户选择独立备考页，优点是考试资料集中、现有课程结构稳定；备选的逐课插入资料会分散备考入口。这次保留既有课程数量、图片与学习路径，通过原课链接复用教学资产。

## 验收

- 首页可进入备考页；本机与 GitHub Pages 子路径可用。
- 每项资源有机构、用途、适用范围和核验状态，官方与原创练习清晰区分。
- 三张图片加载，回忆时隐藏答案，主动揭晓后显示原文；无语音、存储受限、无 JS 时可读。
- 360/390px 手机与桌面无横向溢出，深色模式可用。
- 学习库重建保留入口；原站浏览器回归通过；主仓库保持原分支和原提交。
- 文档提供学习内容规范、逐图 prompt 模板、开发任务 prompt 和验收清单。
